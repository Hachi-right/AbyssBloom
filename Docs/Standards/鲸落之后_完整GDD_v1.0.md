# 鲸落之后 游戏设计文档

版本：v1.0　日期：2026 年 9 月 22 日  
项目性质：六人练手项目　引擎：Unity　团队：2 策划、2 程序、2 美术

本文是策划、程序、美术共同使用的实施基线，覆盖核心玩法、剧情、地图、经济、伙伴、战斗、界面、数据和验收。玩法规则依据逐轮确认整理；具体数字、鱼种、首领招式和技术拆分是可替换的首轮设计方案，不代表已完成试玩验证。

**项目定位：2D 侧视水下探索与弹幕战斗游戏。玩家通过走位净化敌鱼，把捕获的小鱼组成四槽伙伴队伍，在自由探索、强化与交易之间取舍，进入鲸鱼体内找回悲伤、恐惧、愤怒和孤独。**

## 01 项目目标与文档使用

### 1.1 产品概览

| 项目 | 设计基线 |
| --- | --- |
| 暂定名称 | 鲸落之后；正式名称可在内容稳定后确定 |
| 核心类型 | 自由探索、自动攻击、弹幕躲避、伙伴构筑、局内成长与局外成长 |
| 战斗视角 | 2D 侧视；上下左右自由游动；无重力下落和平台跳跃 |
| 操作分工 | 玩家控制移动、闪避、交互和装备选择；角色与伙伴自动攻击 |
| 单人体验 | 单机；首版不包含联机 |
| 首发测试平台 | 暂按 Windows PC、键盘与鼠标；用户尚未指定平台，这是实施假设 |
| 体验时长 | 从第一图连续完成四图的主线路线目标 25—40 分钟；自由刷取、初次阅读和失败重试会延长总时间 |
| 单局定义 | 从据点出海开始，到死亡、主动结束出海或完成最终结局为止；一局可以只完成一个区域 |
| 长期进度 | 永久属性、货币存款、地图解锁、已找回情绪、鱼类图鉴 |
| 制作范围 | 一个据点、四张情绪地图、四个独立首领、十二种可收集鱼、一个完整结局 |

开发目标是做出可解释、可扩展且能完整游玩的系统。没有活动截止时间，开发仍按里程碑推进：先验证一张图的闭环，再生产其余内容。

### 1.2 三个体验支柱

1. **收集有即时影响。** 捕获新鱼后，装备立刻改变攻击表现或生存方式；玩家看得出哪个伙伴正在发挥作用。
2. **探索提供选择。** 地图可以往返，普通战斗可重复，任务与稀有奖励有限；玩家决定何时停止准备并挑战首领。
3. **情绪通过行动被理解。** 需要净化的是恶意，正常情绪需要被接纳。四场首领战分别考验恢复节奏、判断安全区、克制贪攻和寻找回应。

### 1.3 标记约定

- **已确认规则**：后续实现应遵守，修改需要重新讨论。
- **设计基线**：为了使文档可实施而给出的具体规则，团队可提出修改。
- **测试参数**：初始数值，须根据实机数据调整。
- **后续版本**：不计入本文首版完成条件。

## 02 已确认决策与实施假设

### 2.1 已确认决策

| 编号 | 已确认内容 |
| --- | --- |
| D01 | 玩家自由移动、角色自动攻击，操作重点为走位和能力选择 |
| D02 | 2D 侧视水下自由游动，无平台重力 |
| D03 | 敌鱼被击败即净化，转为可拾取的友善鱼；原本友善的鱼无需战斗即可收集 |

| D12 | 击败首领后，当前携带的永久货币自动存入局外账户，之后死亡不影响已存入部分 |
| D13 | 死亡结束本局，携带资源直接损失，不设置尸体或遗物回收 |
| D14 | 玩家可从已解锁的地图开始新一局 |

| D21 | 项目无 Game Jam 时间限制；团队为 2 策划、2 程序、2 美术；使用 Unity |

### 2.2 为实施补充的基线

以下内容由本案提出，尚未单独逐项确认。它们不会被表述为用户已经指定的要求。

- 首版按 PC 键鼠设计；手柄与网页版本放到平台确认后安排。
- 地图内部使用手工设计的连接区域，不做程序随机生成；每局随机普通鱼群组合与商店商品。
- 新地图解锁需要完成当前地图任务并首次击败首领。跨入新地图后，本局不再返回旧地图；同一地图内部可以自由往返。
- 初始四大洋鲸群来自同一片余声云海，玩家进入其中的主鲸。四种情绪恢复后，共鸣传遍鲸群，使洪水中的异常云海退回天空；其他鲸鱼只出现在背景和结局中。
- 正常通关或首领后返航同样结束本局，鱼、金币和临时道具不进入局外收藏。永久保存的是图鉴、剧情和已存入潮晶。
- 角色有基础攻击和通用闪避；鱼的能力自动触发，首版不另外增加主动鱼技能按键。
- 永久货币采用暂定名称“潮晶”。内容解锁由里程碑完成，不使用潮晶购买，确保潮晶专用于永久属性。

这些基线优先在首个可玩版本中检验。鱼种、首领演出、跨地图回溯和平台选择允许单独修订，不必重写双货币和四槽伙伴规则。

## 03 世界观与叙事目标

### 3.1 世界起源

人类没有被听见的话、遭到忽略的心愿，以及被长期压下的情绪，会化为极轻的“余声”，升入大气。余声逐渐聚集，孕育出四头鲸鱼和一片尚未落地的海。

当云层再也无法承载它们，鲸鱼分别坠入四大洋。腹中的云海进入现实，暴雨和上涨的海水淹没了城市。奇幻小鱼随之落下，带着人类曾经的记忆，在旧世界遗迹之间繁衍。

许多年后，幸存的人类生活在浮岛和高楼屋顶。鲸群仍承载着大量未被接纳的情绪；其中的恶意凝结为会攻击人的暗流，依附于小鱼，形成敌对状态。

玩家是灾后出生的年轻拾海人。其家园浮岛附近的鱼群突然迁徙，支撑浮岛的浮力逐渐减弱。玩家出海寻找原因，跟随鱼群进入主鲸的情绪空间。

### 3.2 五类角色与阵营

| 阵营 | 身份与动机 | 游戏中的职责 |
| --- | --- | --- |
| 人类 | 在失去陆地后重新生活，彼此关系并非只有冷漠 | 玩家、据点居民、记忆中的普通人 |
| 友善小鱼 | 承载关怀、勇气、希望、信任等积极回应 | 可直接收集，装备后提供能力 |
| 敌对小鱼 | 被恶意依附，行为具有攻击性 | 发射弹幕，击败后净化为对应可收集鱼 |
| 鲸鱼 | 积压情绪的承载者，没有以淹没世界为目的的计划 | 世界空间、剧情主体与最终解放对象 |
| 商人 | 熟悉鱼类与拾荒工艺的人类旅行者 | 局内交易、扩容、教程与轻量对白 |

**物种与阵营是两个字段。** 同一种鱼可以存在友善外观和恶意依附外观。净化后保留物种，改变行为和视觉状态。玩家不是把悲伤打成快乐，而是在恶意消散后找回其中仍能与人建立联系的生命。

### 3.3 四种情绪的表达

| 情绪 | 被忽视的需求 | 区域中的表现 | 找回时的领悟 |
| --- | --- | --- | --- |
| 悲伤 | 允许失去、允许停下来 | 被水覆盖的房间、没有送出的告别 | 我可以难过，也可以继续生活 |
| 恐惧 | 寻求安全与保护 | 回避目光的通道、过早关闭的门 | 害怕能够提醒我寻求帮助 |
| 愤怒 | 边界被侵犯后的回应 | 被反复抹去的文字、不断升压的腔室 | 我有权说不，也能选择表达方式 |
| 孤独 | 被看见、被回应 | 无人接听的电话、遥远但仍闪烁的灯 | 我可以试着发出声音，等待回应 |

首领是包裹情绪的恶意结壳。战斗解除结壳，短小的事件让玩家与被遮蔽的情绪建立联系。四种情绪本身不作为必须消灭的对象。

### 3.4 主角与商人

主角暂称“拾海人”，造型延续叶片头饰、补丁衣物和短靴。主角使用手作的泡壳装置在水下活动，不设置氧气倒计时。其动机从修复浮岛，逐渐扩展为理解旧世界并帮助鲸鱼释放积压。

商人暂称“阿渡”，使用同一套角色资产出现在各区域中转站。商人回收多余鱼，将它们安置到自己的浮游养场，用于交换物资；出售不表现为杀鱼或拆解。永久属性在据点的“调息台”购买，由相同角色或固定装置提供，不额外制作完整 NPC 系统。

## 04 体验结构与核心循环

### 4.1 局内循环

进入已解锁地图 → 探索支路与任务地点 → 躲避弹幕并净化敌鱼 → 拾取鱼和资源 → 暂停整理背包、装备或强化 → 在安全商店出售与消费 → 完成区域任务 → 挑战首领 → 自动存入携带潮晶 → 继续探索、进入新地图或返航。

普通鱼群可以重复挑战，帮助玩家补足搭配；探索节点提供有限的潮晶和任务进度；首领是永久收益的存入节点。

### 4.2 局外循环

查看本次结算 → 使用已存入潮晶购买有限的永久属性 → 查看新解锁地图与图鉴 → 选择出海起点 → 领取该起点的临时伙伴补给 → 开始新一局。

### 4.3 三种节奏

| 时间尺度 | 玩家主要决策 | 反馈 |
| --- | --- | --- |
| 1—10 秒 | 向哪里移动、是否闪避、先离开哪片弹幕 | 命中、擦身、净化与掉落 |
| 1—5 分钟 | 留哪条鱼、强化谁、卖什么、是否探索支路 | 四槽搭配、背包变化、商店购买 |
| 一次或多次出海 | 从哪张地图开始、何时挑战首领、永久属性如何投入 | 潮晶存入、区域解锁、情绪找回 |

### 4.4 通关与结束条件

- 区域完成：区域任务完成，首领净化，情绪事件完成。
- 剧情通关：四个情绪标记都为已找回。可以分多局累计，不要求同局完成。
- 正常返航：首领战后可从中转站结束本局；只保留已存入潮晶和永久进度。
- 主动放弃：任何时候可从暂停菜单放弃出海，资源损失等同死亡。
- 死亡：生命归零，立即停止攻击、生成与拾取，进入死亡结算。
- 通关后：据点新增“重访记忆”入口，继续游玩原地图；以记忆回访解释鲸鱼已消散后的重复挑战，不撤销结局。

## 05 视角 操作与玩家基础规则

### 5.1 输入方案

| 输入 | 行为 |
| --- | --- |
| W A S D 或方向键 | 水下平面移动；斜向速度归一化 |
| 空格 | 朝当前移动方向闪避；无方向输入时沿上次移动方向 |
| E | 拾取友善鱼、对话、打开商店、激活任务与地图出口 |
| Tab 或 B | 打开或关闭背包，暂停世界模拟 |
| Esc | 暂停菜单；关闭上层弹窗后再关闭下层界面 |
| 鼠标 | 操作背包、商店、菜单和提示，不承担战斗瞄准 |
| M | 展开当前地图与已发现连接 |

自动攻击在有合法目标时执行。安全区、剧情暂停、背包、商店和结算界面中停止战斗。交互键优先选择屏幕提示的对象，同一时刻只显示一个主交互提示，可通过移动切换。

### 5.2 基础参数

以下数值以 Unity 世界单位和秒为单位，是首轮测试参数。

| 参数 | 初值 | 说明 |
| --- | --- | --- |
| 最大生命 | 100 | 永久提升上限额外 20；局内加成另算 |
| 移动速度 | 5.2 单位每秒 | 无惯性漂移；方向切换应干净 |
| 角色受击半径 | 0.28 单位 | 小于角色绘制轮廓，提供可见判定中心 |
| 基础攻击伤害 | 7 | 没有伙伴也能击败浅层普通敌人 |
| 基础攻击间隔 | 0.8 秒 | 理论单体输出 8.75 每秒 |
| 自动索敌距离 | 9 单位 | 需要目标存活、敌对、可见且无遮挡 |
| 基础弹速 | 12 单位每秒 | 飞行距离上限 12 单位 |
| 闪避位移 | 2.8 单位 | 持续 0.18 秒，期间无敌 |
| 闪避冷却 | 2.2 秒 | 无法穿越实体墙体 |
| 受击无敌 | 0.7 秒 | 防止同一批弹幕瞬间多次扣血 |
| 普通接触伤害 | 6 | 普通鱼接触和弹幕共享受击无敌 |
| 金币吸附半径 | 1.2 单位 | 自动吸附金币与潮晶，不自动吸入鱼 |
| 鱼交互距离 | 1.3 单位 | 接近后按 E 拾取，避免满包时持续弹窗 |

自动索敌默认选择最近的合法敌人，每 0.2 秒检查一次。已有目标仍合法时，只有新目标至少近 20% 才切换，减少弹道左右跳动。敌对状态消失后立即清除目标，绝不继续攻击已净化的小鱼。

### 5.3 伤害计算顺序

玩家基础弹丸伤害 =（7 + 鱼提供的固定伤害）× 永久攻击倍率 × 临时攻击倍率 × 分裂弹丸系数。

跟随鱼伤害 = 物种基础伤害 × 该鱼等级倍率 × 永久攻击倍率 × 临时攻击倍率。修改“玩家基础弹丸”的能力不改变跟随鱼攻击，除非词条明确写“全部攻击”。

同一类别的百分比加成相加，不同类别相乘。最后保留内部小数，显示伤害取整；生命不在每次计算时反复取整。每枚弹丸对同一目标最多命中一次，避免穿透弹在碰撞体中重复结算。

首版不加入暴击、元素克制、复杂防御穿透和随机词条，以保证构筑效果容易比较。可用弹丸数量、穿透、频率、固定伤害和防御辅助形成差异。

### 5.4 生存与辅助规则

- 无氧气条、饥饿和体力消耗；危险来自可见弹幕、敌人和地形机关。
- 普通伤害不可将同一帧内生命重复扣至异常值；死亡事件只触发一次。
- 治疗不超过最大生命。增加最大生命不会同步赠送当前生命；降低最大生命时仅将当前值限制在新上限内。
- 换装不会重置闪避或伙伴技能冷却；同物种冷却保存在本局物种状态中，避免反复装备刷护盾和治疗。
- 移速总加成上限为 35%；减速不使玩家低于基础速度的 60%；减伤总上限为 40%。

## 06 净化 捕获与掉落

### 6.1 敌鱼状态流程

敌对生成 → 移动与攻击 → 生命归零 → 停止攻击并移除伤害碰撞 → 0.35 秒净化演出 → 生成友善鱼拾取对象与金币 → 玩家按 E 收入背包。

敌鱼归零时，其尚未命中的弹幕在 0.2 秒内淡出并失去伤害。首领战中的弹幕由首领单独管理。每条普通敌鱼必定产出一条对应物种的 Lv1 鱼，不额外进行“能否捕获”的概率判定。

原本友善的鱼使用游动、靠近玩家和交互提示表现可收集状态；它们不会被自动索敌，也没有必须击败的生命条。

### 6.2 掉落规则

| 来源 | 鱼 | 金币 | 潮晶 |
| --- | --- | --- | --- |
| 普通敌鱼 | 对应 Lv1 鱼一条，必定 | 按地图与敌型掉落 | 不掉落 |
| 首次击败本局精英 | 对应 Lv1 鱼两条 | 普通敌的四倍 | 固定 2 |
| 重返区域刷新的普通鱼群 | 正常产出 | 正常产出 | 不掉落 |
| 原本友善的鱼 | 可直接收集一条 | 无 | 无 |
| 探索潮晶节点 | 无 | 可配置为无 | 每节点 1，本局一次 |
| 区域任务 | 一条指定鱼或补给 | 固定任务奖励 | 固定 2，本局一次 |
| 首领 | 不占用伙伴槽的剧情奖励 | 固定金币奖励 | 基础 4，首次剧情完成额外 4 |

精英和原生友善鱼的固定点位本局不刷新。普通敌刷新可以无限提供鱼和金币，但不能直接提供潮晶，防止站在低风险区域就完成全部永久成长。

### 6.3 满包与地面物品

背包不足时不自动销毁鱼，不自动转换金币。提示“背包空间不足”，提供“整理背包”入口。打开背包会暂停，玩家可强化、装备或丢弃，再关闭背包拾取。

未拾取物品记录在其区域中，离开再返回仍存在，直到结束本局或跨图离开当前地图。相同物种的地面对象超过表现阈值时合并为鱼群标记，保留准确数量。首轮阈值为每区 20 个可视拾取对象，超过后合并，不删除奖励。

拾取按整条鱼计算。拾取鱼群时按剩余容量取得能容纳的数量，其余仍在原地。所有生成和拾取使用唯一标识，防止区块切换、存档恢复或连续按键导致重复奖励。

## 07 背包与装备

### 7.1 容量规则

初始背包容量为 12 点，小、中、大型鱼分别占 1、2、3 点。相同鱼可在界面堆叠显示，但占用为“数量 × 单条体积”，不会因堆叠减少空间。

装备伙伴只占四个伙伴槽，不占背包。使用型道具单独计数，首版上限为每种 3 个，不占鱼背包；这个处理属于设计基线，用于避免恢复药与鱼抢占同一套容量规则。

### 7.2 装备与换装

装备条件为拥有该鱼、存在空槽或指定替换槽、四槽中没有同种鱼。两类鱼共用槽，不规定必须各装备几条。

换装必须先模拟最终背包状态，再一次性提交：新占用 = 当前占用 − 取出的新鱼体积 + 放回的旧鱼体积。结果超过容量时阻止操作，保留全部原状态，并显示还需腾出的点数。

例：当前 11/12，背包中一条占 1 点的新鱼替换占 3 点的已装备鱼，结果为 13/12，操作失败；如果新鱼占 3 点、旧鱼占 1 点，结果为 9/12，允许替换。

直接卸下伙伴必须有足够背包空间。丢弃已装备鱼需先卸下，避免误触直接失去能力。商店允许直接出售装备鱼，但显示“出售后失去该能力”的确认。

### 7.3 背包交互

左侧显示四个伙伴槽，右侧显示按物种分组的背包列表。选择鱼后显示类型、等级、强化进度、体积、出售价格及当前效果。

主要操作为装备、替换、强化和丢弃；出售仅在商店显示。支持点击按钮完成全部操作，拖拽是后续增强，不作为首版必需条件。

关闭背包时继续原有模拟，不跳过弹幕时间。背包、地图、商店和菜单采用统一暂停计数；关闭一个窗口不能意外解除仍在其他窗口中生效的暂停。

## 08 伙伴 强化与能力叠加

### 8.1 两种伙伴表现

跟随型鱼围绕玩家分配固定的四个候选位置，无受伤和碰撞推挤。它们自动追随，按技能需要短距离游出、攻击或提供护盾，随后返回。跟随鱼不可死亡，避免额外救援和复活负担。

附着型鱼化为玩家装备上的鳞片、晶体、尾鳍或轻量环绕特效。实际鱼形保留在装备图标和图鉴中；每个附着效果都有可辨识的攻击或身体变化。

### 8.2 等级与强化投入

最高等级为 Lv5。消耗同物种的鱼提供强化投入，不消耗金币。素材可以来自背包，不能直接消耗其他已装备对象。

| 等级 | 升到下一级所需普通同类鱼 | 累计强化投入 | 基础攻击型鱼伤害倍率 |
| --- | --- | --- | --- |
| Lv1 | 1 | 0 | 1.00 |
| Lv2 | 2 | 1 | 1.15 |
| Lv3 | 3 | 3 | 1.35 |
| Lv4 | 4 | 6 | 1.55 |
| Lv5 | 无 | 10 | 1.80 |

一条普通鱼从 Lv1 到 Lv5 共需额外 10 条同类鱼，连本体共 11 条。部分投入保留，例如 Lv3 且投入 5/10，距离 Lv4 还需 1 条。

强化过的鱼也可作素材，贡献为“1 + 已投入数量”。例如投入 3 条素材的 Lv3 鱼，作为素材贡献 4。总投入超过 10 时不允许确认该素材组合，避免不提示就浪费高等级伙伴。所有消耗在预览中显示。

升级只强化原有效果，首版不另做每条鱼的分支技能树。不同物种形成构筑，同物种强化提升强度。

### 8.3 叠加与冲突

- 每种鱼最多装备一条，因此不会发生同种光环重复叠加。
- 改变弹道的鱼与增加伤害、穿透的鱼可以组合；先生成最终弹道，再赋予伤害和穿透参数。
- 同类减速取最高值，刷新持续时间，不连乘至无法移动；首领受到的减速为普通目标的一半。
- 护盾只保留当前数值更高者，不将多次刷新相加；卸下护盾来源鱼后该护盾消失。
- 攻击型鱼使用统一等级倍率；功能型鱼使用明确的分级数值，不能再重复乘攻击倍率。
- 自动攻击只能在有敌对目标时触发，不能通过攻击友善鱼刷命中或治疗效果。

## 09 双货币与结算

### 9.1 两种货币

| 货币 | 存放位置 | 来源 | 用途 | 死亡处理 |
| --- | --- | --- | --- | --- |
| 金币 | 本局钱包 | 普通敌、精英、任务、首领、出售鱼 | 局内商店购买鱼、道具、背包扩容 | 全部损失，不进入局外 |
| 潮晶 待存入 | 本局携带栏 | 有限探索节点、首次击败本局精英、任务、首领 | 无法直接消费，等待首领胜利结算 | 全部损失 |
| 潮晶 已存入 | 局外账户 | 首领胜利时转入 | 仅购买永久属性 | 永久保留 |

潮晶的待存入与已存入是同一种货币的两个存放状态，不是第三种货币。界面必须分别标注，不能把两者混成一个总数。

### 9.2 首领胜利的原子结算

1. 首领生命归零，立刻关闭其攻击、清除弹幕和危险地形。
2. 发放本次首领奖励：金币、基础潮晶及首次完成额外潮晶。
3. 将玩家当前携带的全部潮晶存入局外账户，携带值置零。
4. 记录本局首领已完成、永久情绪找回、地图解锁、首次奖励已领取和待播放演出。
5. 一次保存完成后显示“潮晶已存入”，播放情绪事件；事件可以跳过，奖励不会因跳过而丢失。

奖励和存入顺序必须固定，首领本身掉落的潮晶包含在本次存入中。首领不在场景地面生成需要玩家冒险拾取的潮晶。

每次结算具有唯一事务编号。重载、重复动画事件或连续点击不能重复发奖。首领胜利判定一旦进入完成状态，同帧残留弹幕不得再使玩家死亡；若玩家在首领归零前已进入死亡状态，则本次胜利不成立。

### 9.3 探索收益与死亡例子

假设玩家在第二区获得 6 枚待存入潮晶，击败首领获得基础 4 枚，该区域首次完成再获得 4 枚，则立即存入 14 枚。

之后玩家在第三区取得 3 枚潮晶和 90 金币后死亡：局外的 14 枚保留；新取得的 3 枚潮晶、90 金币、本局鱼和临时道具全部损失。

首领战后继续在原地图寻找遗漏，获得的新潮晶仍属于待存入状态。已完成的首领不能再次触发存入；这些新潮晶需要带去下一个尚未完成的首领。返航界面应提醒这一点，避免玩家误认为首领战后自动持续存款。

## 10 商店 道具与局外成长

### 10.1 安全商店

每张地图设置一个中转站，可从多条路线返回。安全区无敌人生成，攻击弹丸不能进入；打开商店暂停世界。商人使用同一角色，随区域改变少量装饰与对白。

商店包含三个页签：出售、补给、扩容。出售支持数量选择和同物种批量操作，已装备或已强化的鱼单独列出，默认不被“出售全部普通鱼”选中。

固定补给每图恢复一次库存；跨入新图恢复库存，反复进出同图商店不补货。鱼商品每图首次进入时生成，使用本局种子保存，退出重进不能免费刷新。

### 10.2 出售与购买价格

普通鱼基础出售价格按体积分别为 8、12、16 金币。地图价格倍率为 1.00、1.25、1.50、1.75。

鱼出售价格 = 向下取整［基础出售价格 × 当前地图倍率 ×（1 + 0.6 × 强化投入）］。

普通 Lv1 鱼购买价格 = 当前地图 Lv1 出售价格 × 3。商店不出售强化鱼。所有商品都显示最终价格，内部价差保证同地图买入再出售不会产生金币。

强化投入的价值可以部分回收，但低于单独出售全部素材；这使“现在强化”具有机会成本。由高等级素材强化时，投入值按贡献完整继承。

扩容购买只在本局生效；商品权限永久解锁。新一局恢复 12 点，可再次购买已解锁阶段。必须依次购买，同一局不能重复购买同一阶段。

从后期地图开始时，相关商品权限按永久进度开放，但不会免费获得已购买过的局内扩容。地图起始伙伴不占背包，因此不会挤占最初收集空间。

### 10.5 永久属性

潮晶只在据点调息台购买以下三类属性。内容解锁不消耗潮晶。

| 永久属性 | 每级效果 | 等级上限 | 各级价格 | 全部购买成本 |
| --- | --- | --- | --- | --- |
| 体魄 | 最大生命加 5 | 4 | 6、10、16、24 | 56 |
| 共鸣 | 全部攻击加 2% | 5 | 6、10、16、24、34 | 90 |
| 游动 | 移动速度加 2% | 4 | 8、12、18、26 | 64 |

全部购买共 210 潮晶。上限是生命增加 20%、攻击增加 10%、基础移速增加 8%，使永久成长有帮助但不取代伙伴构筑。满级后潮晶继续显示库存，首版不新增无限属性购买。

永久属性在开始新一局时读取为本局基础数据；出海途中不能打开局外调息台购买。首次存入至少 6 潮晶后，提示存在可购买升级；没有达到价格时不显示无效的升级引导。

## 11 地图 起点与探索规则

### 11.1 世界结构

据点设于露出海面的旧建筑屋顶。首次出海经过短暂浅海教学，进入主鲸。四张主体地图依次为悲伤、恐惧、愤怒、孤独的记忆生态。

首次通关顺序固定，确保剧情连贯。已解锁后，任何新一局都可以选择其中一图作为起点；从后期图出发不撤销之前找回的情绪，也不要求重新完成早期图。

同一图内部是有环路、支路和捷径的区域网络。前往下一图时显示提示“本次出海将离开当前地图，未拾取物品不会随行”，允许取消。这个跨图限制属于首版基线，未来可替换为完整世界回溯。

### 11.2 标准地图连接

每图采用七个区域作为最初灰盒基线，可根据测试增加或缩减房间，不以生成随机迷宫为目标。

| B 回流通道 | 普通战斗、区域环境机关 | H、A、D |

地图迷雾只遮蔽未访问区域。任务标识在发现线索位置后显示，不要求玩家记住文字地址。普通清理状态、已用宝箱、未拾取鱼、商店和首领状态使用不同图标。

### 11.3 普通敌刷新

一个战斗区没有玩家、且玩家已进入另一个区域后，离开计时开始。经过 20 秒有效游戏时间，普通敌生成组获得刷新资格；玩家再次进入时重置该组到新一轮状态。

刷新是整组重置，不在玩家面前补满。残存普通敌先移除，再生成新组；先前未拾取的掉落保持不变。暂停、商店和背包期间不累计这 20 秒。

首领、精英、固定友善鱼、任务物件、宝箱和潮晶节点使用本局唯一完成标记，不参与普通组刷新。普通敌在小地图上标为“可再现鱼群”，有限奖励标为“本局已获取”，避免玩家分不清。

跨图后的旧图状态可归档以减少运行负担，永久剧情状态独立保留。新的出海会重置局内奖励与首领，但不会再次发放永久首次奖励。

### 11.4 区域任务

每图任务结构相同：找到三处记忆线索，恢复一个核心记忆，开启首领入口。首版通过位置交互完成，不要求消耗指定伙伴，不以背包内是否保留某鱼作为通关条件。

三处线索允许任意顺序获取。线索与地图物件不会占背包。死亡后当前图的局内任务重新进行，但已看过的文本可快速跳过；已永久找回的情绪不会回退。

## 12 普通敌与关卡数值

### 12.1 行为与物种分离

敌人行为模板控制移动和弹幕，物种字段决定净化后的伙伴。一个物种可以搭配两种常规行为模板，但同一张图中保持稳定提示，避免外观相同的敌人出现完全不可预测的招式。

| 行为模板 | 行动 | 首轮参数 | 对玩家的要求 |
| --- | --- | --- | --- |
| 追游者 | 缓慢追踪，靠近造成接触伤害 | 速度 2.2，生命基准 24 | 保持移动，避免被包围 |
| 点射者 | 与玩家保持距离，定时瞄准射击 | 每 2 秒一发，预警 0.4 秒，弹速 3.0 | 改变移动方向 |
| 扇射者 | 固定方向发出扇形弹幕 | 每 3 秒三发，间隔角 18 度 | 识别扇形间隙 |
| 冲刺者 | 预告一条路径后直线冲刺 | 预警 0.7 秒，冲刺速度 8 | 横向离开路径 |
| 环射者 | 发射带固定缺口的环形弹 | 每 4 秒十发，缺口不少于 55 度 | 寻找出口 |
| 护伴者 | 为附近一名敌人提供临时护盾 | 护盾 12，持续 4 秒，间隔 7 秒 | 靠近优先处理辅助目标 |

精英由行为模板加第二种间隔攻击构成，生命为同图普通敌的 3 倍，外轮廓和预警更明显。不是简单把所有弹速翻倍。

### 12.2 地图梯度

| 地图 | 普通敌生命倍率 | 普通弹幕伤害 | 普通敌金币 | 单区同时敌人数 | 普通敌弹速范围 |
| --- | --- | --- | --- | --- | --- |
| 悲伤 | 1.00 | 6 | 1 | 4—6 | 2.4—3.0 |
| 恐惧 | 1.30 | 8 | 2 | 5—7 | 2.6—3.3 |
| 愤怒 | 1.60 | 10 | 2 | 6—8 | 2.8—3.6 |
| 孤独 | 1.90 | 12 | 3 | 6—9 | 2.8—3.8 |

其他模板生命相对基准乘 0.8—1.3，重型鱼采用较高生命与较慢移动。普通战斗单区同时敌人数硬上限 12；若生成会超过上限，则排队延后。

各图新增三种主要伙伴，同时保留旧物种获取途径。普通鱼群物种权重：当前图物种合计 70%，此前已解锁物种合计 30%；第一图只有当前物种，权重归一化。商店保证项为旧伙伴强化提供另一条路径。

### 12.3 自动攻击下的公平性

- 每个危险招式具有可辨识的预警，不能让角色刚进入区域就受到不可避免伤害。
- 区域入口提供至少 1.2 秒无碰撞缓冲，新敌距入口落点至少 3 单位。
- 避免需要“停火才能过关”的反伤设计，玩家不能直接控制停火。
- 需要处理特殊目标时，通过站位靠近改变索敌目标；不设计必须鼠标点中弱点的机制。
- 不使用满屏随机散弹。弹幕需有稳定缺口和方向，安全通道宽度至少为角色碰撞直径的 1.5 倍。
- 地图装饰不遮挡关键弹丸。敌方弹幕、友方攻击、拾取物分别使用形状与描边区别。

### 13.2 首领统一框架

首领分三阶段：生命 100—70%、70—35%、35—0%。跨阶段时清除已失去预警依据的弹幕，给予 1 秒过渡，再启动下一组攻击。阶段变换不额外恢复生命。

首领可被攻击的时间占比目标为 60—80%。长于 5 秒的无敌阶段必须提供明确的行动目标。首领召唤物最多同时 4 个，击败后仅掉少量金币，不掉伙伴鱼或潮晶，防止首领内无限农场。

胜利后不增加第五个必打首领。第四个首领完成最终净化，四种情绪齐全时直接进入结局。

## 14 完整剧情流程与演出脚本

### 14.1 开场

镜头从海底经过一块旧路牌，升到浮岛下方。鱼群正朝远处游去，浮岛的一角慢慢没入水中。玩家用绑带固定自己的泡壳装置。

商人：“撑着这片浮台的小家伙都往同一个方向去了。”

玩家：“我把它们带回来。”

商人：“先带上这个。看到发黑的鱼，别靠得太近。”

镜头切到浅海，开始移动和自动攻击教学。文字不解释全部世界史，玩家先完成一个可理解的生活目标。

### 14.2 第一次净化与装备

一条敌对灯鳍鱼发射单发慢弹。玩家移动躲避，基础攻击自动命中。敌鱼外层暗纹剥落，变成温和的小鱼。

提示：“靠近并按 E，收集灯鳍鱼。”

拾取后自动打开一次背包教学，世界暂停。高亮空伙伴槽，玩家点击装备。关闭背包，灯鳍鱼游到玩家身边，参与下一场战斗。

第二个短教学提供泡灵及一条重复灯鳍鱼，分别演示附着型效果与消耗同类鱼强化。首次强化允许撤销教学选择一次；正式流程不提供消耗撤销。

### 14.3 进入鲸鱼

玩家追随迁徙鱼群，发现远处巨大的轮廓。鲸鱼张开一道发光的缝隙，内部却是旧世界房间的倒影。

回声：“吃饭了，回家吧。”

玩家进入泪潮旧居。画面出现第一条任务：“找到声音的来处。”

### 14.4 中段真相

悲伤事件让玩家第一次知道鱼携带着人类记忆；恐惧事件展现被忽视的求助；愤怒事件解释恶意与情绪的区别；孤独事件让玩家亲自发出回应。

世界起源通过四幅可回看的记忆画面补全：余声升空、云层中出现鲸形、鲸群坠落、海洋覆盖陆地。每幅正文不超过 80 个汉字，不用长日志阻断战斗节奏。

商人在愤怒区的对白：“有些声音压了太久，出来时会伤人。我们得先让它停下来，才能听清它原本想说什么。”

### 14.5 结局

四个情绪标记亮起，鲸鱼腹中的积压开始消散。玩家身边的伙伴引领其穿过逐渐透明的通道。远处四大洋的鲸影彼此回应，云海化为光雨升回天空。

海面下降，旧建筑的门窗和街道缓缓露出。镜头选择缓慢退水，不表现突然抽空海洋造成的第二次灾难。自然海洋继续存在，带来洪水的异常水体离开现实。

失去家园的人并非立即恢复旧生活。画面中有人修桥，有人晾晒物品，有人在新露出的路口等待同伴。灾难中发生过的失去不会被倒带抹除。

玩家站在曾经只能从水下看见的路牌旁，把湿漉漉的脚放到地面上。

商人：“想好往哪里走了吗？”

玩家看向伙伴，又看向远处的浮岛。

玩家：“先回家。然后，再去看看。”

结束字幕：“潮声退去，声音终于被听见。”

### 14.6 叙事边界

- 不宣称悲伤、恐惧、愤怒、孤独需要被治愈到完全消失。
- 不将灾难解释为某个受伤者或某类情绪应该承担的道德惩罚。
- 不通过结局复活所有逝者；陆地恢复带来重建的可能，记忆和伤痕仍存在。
- 主角不需要突然成为心理治疗师。对话保持具体的人和事，用行动完成回应。
- 这些是故事表达原则，不在玩家界面中变成说教提示。

## 15 新手引导与进度解锁

### 15.1 前五分钟目标

| 时点目标 | 内容 | 验收表现 |
| --- | --- | --- |
| 0—30 秒 | 移动、观察角色自动攻击 | 玩家无需说明就能移动并击中教学敌 |
| 30—60 秒 | 第一次净化和拾取 | 玩家知道敌鱼会变成伙伴资源 |
| 1—2 分钟 | 装备灯鳍鱼、泡灵 | 能区分跟随与附着效果 |
| 2—3 分钟 | 消耗同类鱼强化 | 理解重复鱼有强化与出售两种价值 |
| 3—4 分钟 | 进入商店，出售一条备用鱼 | 理解金币属于局内消费 |
| 4—5 分钟 | 发现潮晶与未存入提示 | 理解需要击败首领才能安全保存 |

### 15.3 重复挑战的叙事处理

同一首领重访只播放短入场和净化演出，首段长剧情默认跳过，图鉴中可回看。区域任务用“重整记忆”标识重复目的，系统仍按本局任务规则提供奖励。

已解锁地图作为新起点时，不重播此前鲸鱼入口教学；通过简短航行转场直接到相应中转站。

沿用植物、晶体、贝壳、铜色构件和修补布料，形成可亲近的水下生活感。废土通过被自然覆盖的生活遗物表现：路牌、窗框、灯具和旧站台被重新使用，而不是让所有场景都灰暗残破。

### 17.2 形状与色彩

- 主角保持轻盈、圆润、可读的整体轮廓，叶片和披肩提供游动方向反馈。
- 普通鱼减少密集纹样，确保缩小后可识别；越古老的生物保留越丰富的附生物和装饰，复杂度集中到首领。
- 友善鱼使用舒展的鳍和稳定的微光；敌对状态添加收紧的姿态、断续暗纹和明显的恶意结壳。
- 四图主色分别以青蓝、冷青紫、锈红橙、深蓝金为基线；危险弹幕使用高对比轮廓，避免与同色背景混在一起。
- 治愈感来自生物动作、光线和人与旧物的关系，战斗时仍需要清晰有力的命中反馈。

颜色方案属于参考提案，最终值由美术在同一战斗测试场里确定，不能只根据单张立绘定色。

### 17.3 战斗表现优先级

从高到低依次是敌方危险、玩家受击中心、可交互物、玩家与伙伴、友方攻击、背景装饰。友方弹幕降低不透明度和描边强度，首领预警始终位于场景装饰之上。

跟随型伙伴保留轮廓与移动姿态，队伍不挡住玩家中心。附着型效果最多保留两层身体常驻表现，多余效果在攻击时展示，避免四槽满载后成为看不清的光团。

## 18 音频与反馈

背景音乐以低强度水下氛围为底，进入战斗后增加节奏，首领阶段切换通过乐层变化提示。情绪找回后减少紧张音色，保留短暂留白。

| 声音类别 | 功能 | 制作基线 |
| --- | --- | --- |
| 玩家攻击与伙伴攻击 | 反馈攻击节奏 | 同屏高频音限流，避免四伙伴叠成噪声 |
| 受击与危险预警 | 提醒生存风险 | 优先级高于普通命中音 |
| 净化与拾取 | 表达战斗成果 | 两种不同声音，防止误以为击败即已入包 |
| 强化与交易 | 确认资源变化 | 升级、售出、购入各一组短音 |
| 潮晶存入 | 明确收益安全 | 与普通金币拾取明显不同 |
| 四首领 | 建立记忆与预警 | 每首领至少一个标志音和三个招式提示 |
| 情绪事件 | 衬托表达 | 可用文本配环境音，首版不要求全语音 |

## 19 内容规模与数值验证框架

### 19.1 首版必须完成的内容

必须完成四图、四首领、十二种鱼、两种货币、四槽伙伴、强化、容量背包、局内商店、永久属性、地图起点选择、跨局情绪记录、完整结局、存读档和设置。

首次可玩切片只实现第一图、三种鱼、一个首领与完整经济闭环；它是内部里程碑，不等于最终交付范围。首版不包含联机、随机词条、装备稀有度、养殖经营、程序随机地图、额外第五首领和无限成长树。

### 19.2 体验时长预算

| 部分 | 主线熟悉路线参考 |
| --- | --- |
| 首次浅海教学 | 2—3 分钟，重访省略 |
| 每图普通战斗与移动 | 3—4 分钟 |
| 每图任务和商店 | 1—2 分钟 |
| 每图首领 | 1—2.5 分钟 |
| 跨图和结局 | 合计 1—3 分钟 |

以四图合计约 25—40 分钟作为调优目标，不把自由探索玩家超时视为失败。第一遍陌生路线、阅读、重复刷鱼和死亡造成的总时长需在测试中另外记录。

### 19.3 输出与生命预算

基础攻击每秒 8.75 伤害；两条攻击或增伤伙伴的早期构筑，静态理论输出目标约 18—30；四槽后期输出构筑约 45—70。实际有效输出受走位、弹道命中和首领窗口影响，不能把理论值直接当作实战值。

例：Lv5 灯鳍鱼、针尾鱼、归灯鱼、焰尾鱼的静态单体理论输出，在无永久和临时加成、全部弹丸命中的条件下为 14.4 + 21.6/1.4 + 25.2/1.4 + (7+8)/0.8，约 66.58 每秒。它没有防御辅助，属于输出上界示例。

按有效命中与可攻击时间合计为理论输出的 35—60% 估算，第三区、第四区首领生命对应约一分钟至两分钟上下的战斗区间。最终持续时间必须用实机测试校准，不以这个估算保证时长。

### 19.4 金币预算

区域任务金币按四图分别为 20、25、30、35；首领金币分别为 30、45、60、80。背屋蟹加成按既定规则作用于这些奖励。

每图主线消灭普通敌数量目标 25—45，另有 2 精英。第一区通过基础金币和出售部分备用鱼，应能在首领前购买至少一项有感升级；希望同时买到大量道具和多次扩容的玩家需要增加探索或重复战斗。

无限刷新使金币不存在严格的全局上限。经济设计的重点是达到合理搭配所需时间、是否出现无意义等待，以及是否有单一物种始终是最佳出售选择。

### 19.5 需要记录的测试数据

- 首次净化、拾取、装备和强化分别用时。
- 每张图停留时间、往返次数、普通敌重复击败次数。
- 四伙伴使用率、等级分布、替换次数和最终构筑。
- 背包打开频率、满包次数、因容量失败的换装次数。
- 获得、消费和结算金币；获得、损失和存入潮晶。
- 每个首领的尝试次数、用时、受击来源和死亡位置。
- 玩家对正面小鱼、恶意、四种正常情绪关系的理解。

初始验收目标：多数首次玩家在 90 秒内完成第一次装备；首领前至少做出一次强化或购买选择；背包管理不应长期占据总游玩时间的三分之一以上。若达到目标仍感觉乏味，以实测体验继续调整。

### 19.6 调参顺序

先调整移动、碰撞和弹幕预警，再调整普通鱼输出与伙伴基础效果；之后调整首领生命和招式间隔，最后调整金币、扩容与永久属性价格。不要用大量永久攻击加成掩盖基础战斗不好玩的情况。

### 20.3 事务与防重复

装备、强化、购买、出售和首领结算均采用“检查 → 计算结果 → 一次提交 → 保存 → 展示反馈”。任何检查失败不应先扣钱、删鱼或卸装。

首领事务编号由本局 ID、地图 ID、首领 ID 组成。永久首次奖励额外使用永久完成标记，确保下一局可以领取基础奖励，却不能重复领取首次奖励。

调试工具可以批量加资源、跳图和解锁，但正式构建中不展示入口。测试档与正式档分开，避免测试过程中误判首次奖励。

### 20.4 存档策略

永久数据与当前本局数据存放在同一个逻辑存档中，使用版本号、临时写入、完整性检查和上一份备份。尤其首领存入时，局外潮晶增加和局内潮晶清零必须同时完成。

自动保存节点为出海创建、物品交易、强化与换装完成、任务节点完成、区域切换、首领结算和返航。拾取可短时间合并写入，首轮建议最多延迟 1 秒；正常退出时先完成挂起保存。

挂起恢复保存玩家位置与生命、伙伴冷却、存活敌人的位置和生命、已完成状态、物品与刷新计时。不强制逐粒保存弹幕：恢复时清除瞬时弹丸，提供 1 秒重建缓冲，玩家和敌人都不能攻击；已死亡敌人不复活，奖励不重发。

若主档损坏，显示恢复提示并尝试上一份完整备份，不静默删除永久进度。首版只需一个正式存档槽与一个自动备份槽，不做云存档和跨设备同步。

### 20.5 性能与实现边界

首轮性能目标为团队约定的参考 PC 在 1080p 下保持 60 帧，机器配置需在测试记录中填写，不能只写“所有电脑流畅”。普通战斗敌人上限 12，敌方活动弹丸测试上限 160，友方 80，地面物品采用合并表现。

弹丸、净化反馈、飘字和掉落表现使用对象复用，避免持续生成销毁造成波动。弹丸达到上限时通过发射器预算延后新一轮攻击，不能随机删除玩家正在躲避的危险弹幕。

所有技能冷却、刷新、临时效果和攻击周期使用统一游戏模拟时间；暂停不结算收益、不恢复护盾、不使敌人刷新。界面动画可使用独立时间，不影响游戏状态。

## 22 验收用例与主要风险

### 22.1 核心系统验收

| 编号 | 测试情境 | 预期结果 |
| --- | --- | --- |
| T01 | 玩家附近同时有敌鱼和友善鱼 | 自动攻击只针对敌鱼 |
| T02 | 敌鱼归零后仍有原目标引用 | 立即停止敌对攻击，净化鱼不可继续受伤 |
| T03 | 连续拾取同一个掉落对象 | 只生成一个鱼实例 |
| T04 | 四槽已有某种鱼，再装备同种 | 拒绝重复装备，保留背包对象 |
| T05 | 11/12 背包，以 1 点鱼替换 3 点伙伴 | 预计 13/12，操作失败且原状态完全保留 |
| T06 | 使用强化过的同类鱼作素材 | 按 1 加已投入数量贡献，结果正确，素材只消耗一次 |
| T07 | 强化将超过 10 投入 | 阻止确认，说明超出，不吞材料 |
| T08 | 反复卸下和装备水母 | 冷却不重置，不反复获得免费护盾 |
| T09 | 开包等待 30 秒 | 敌人、弹丸、冷却、刷新、临时效果都不推进 |
| T10 | 商店打开后再打开详情并关闭详情 | 商店仍使游戏暂停 |
| T11 | 背包满时拾取鱼 | 地面鱼保留，可整理后再次拾取 |
| T12 | 离开区域 20 秒后返回 | 只刷新普通生成组，不重复精英和有限奖励 |
| T13 | 反复进出同图商店 | 库存与商品不免费刷新 |
| T14 | 金币不足时购买或刷新 | 不扣款、不发商品、不变库存 |
| T15 | 首领胜利时携带 6 潮晶，奖励 4 | 至少存入 10；首次额外奖励按永久标记另加 |
| T16 | 首领结算动画重播或恢复存档 | 不重复存入和发放首次奖励 |
| T17 | 已存入 14，携带 3 并死亡 | 账户保留 14，携带变为 0，本局资源清空 |
| T18 | 同帧首领归零与残留弹幕命中 | 按明确的胜利锁定规则结算，不出现存入后又回滚 |
| T19 | 已解锁第三区，选择其出海 | 只发一次第三区补给，不发前两区奖励 |
| T20 | 在不同出海中完成四种情绪 | 标记累计，最后一种完成后触发结局 |
| T21 | 直接进入已通关地图重访 | 只发基础奖励，不重复首次奖励和长剧情 |
| T22 | 正常退出并继续 | 恢复同一局，已拾取物不再次出现，背包与账户一致 |
| T23 | 主存档不可读 | 尝试有效备份并明确提示，不静默清除全部进度 |
| T24 | 无指定鱼进入任意首领战 | 可以通过移动与基础攻击完成机制，不出现必须某鱼的软锁 |
| T25 | 从第四图使用最低补给与无永久攻击开始 | 能处理入口普通敌并获得成长，不因空装立即无法推进 |

### 22.2 体验风险与处理

| 风险 | 观察信号 | 优先处理 |
| --- | --- | --- |
| 每次拾取都要开包，节奏破碎 | 背包占用时间超过总时间约三分之一 | 提升早期容量、合并列表、减少无意义交互，不先删除取舍 |
| 玩家只在低难区刷鱼 | 停留超过主线目标很久且没有新选择 | 改善商品保底与物种分布，明确首领准备提示 |
| 永久货币进展过慢 | 多次失败后完全无进展并放弃 | 降低早期首领门槛或首级价格，不破坏击败首领才存入的规则 |
| 某鱼始终必选 | 所有成功构筑都依赖同一物种 | 比较真实输出与防御贡献，先修异常叠加再调基础数值 |
| 自动攻击不听使唤 | 玩家不断靠近某目标仍攻击别处 | 调整索敌稳定性、合法目标和视线判定 |
| 首领只有堆弹幕区别 | 玩家无法描述四场不同的行动方式 | 强化各自的缺口、判断、冷却和灯位机制 |
| 画面漂亮但敌弹看不清 | 受击玩家无法指出来源 | 降低友方特效、调整描边与背景明度 |
| 后期起点奖励过多或过少 | 直达图比连续探索明显失衡 | 单独调整起点补给，不改变已有地图永久进度 |
| 情绪主题被理解为消灭负面情绪 | 测试者说悲伤是不该存在的 | 修改敌人命名、事件文本和净化演出，明确结壳与情绪区别 |
| 范围持续扩张 | 一图闭环未完成就新增大量系统 | 按里程碑验收，额外内容归入后续版本 |

### 22.3 首版完成定义

在干净存档中，玩家能够完成教学、捕获并搭配鱼、强化与交易、扩容、探索往返、挑战首领并存入潮晶；死亡后规则正确；可以购买永久属性，从已解锁图再次出海，最终分局完成四种情绪并观看陆地恢复结局。

四图都有独立首领和可辨识的主题表现。正常退出可继续，核心物品事务无已知复制或丢失问题。操作说明、素材说明和已知问题与可运行构建一并提交。

## 23 尚可调整的事项与版本维护

已确认的双货币、首领存入、死亡损失、四槽装备、普通敌刷新和跨局情绪进度是当前系统基础。以下项目在实施前或首轮测试后继续收敛，不必等待所有数字最终确定才开始灰盒。

| 事项 | 本文当前处理 | 何时再确认 |
| --- | --- | --- |
| 首发平台 | Windows PC 键鼠 | 开始输入与构建设置前 |
| 四大洋鲸群与主鲸关系 | 同源共鸣，其他鲸鱼只做叙事表现 | 剧情分镜前 |
| 跨图返回 | 同图往返，跨入新图后本局不返回旧图 | 地图流程灰盒完成时 |

| 永久属性上限 | 生命加 20、攻击加 10%、移速加 8% | 进行多局连续测试后 |

规则改动先更新本表及对应章节，再同步配置与验收用例。调整价格不应暗中改变永久与局内的边界，修改首领奖励必须同步更新存入顺序、预算和测试例子。

本文件完成的是设计方案与实施基线。实际游戏尚未由本任务实现，数值尚未经过玩家试玩；文中的性能、时长和体验指标均为后续验收目标。
