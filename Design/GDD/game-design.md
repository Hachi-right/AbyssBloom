## 1. 玩法综述

### 1.1 一句话定位

**一款深海弹幕射击 + 情绪生物收集 + 增量养成的 2D 独立游戏。**
玩家驾驶潜艇潜入被淹没的世界，在情绪鱼群的弹幕中穿行，捕获正面情绪、净化负面情绪，把找回的情绪送还世界。

### 1.2 玩法标签组合

| 标签 | 在本作中的体现 |
| --- | --- |
| **弹幕射击** | 负面情绪鱼发射情绪弹幕，玩家在弹幕中走位、闪避、反击 |
| **生物收集** | 捕获的鱼进入背包，成为能力来源或交易品 |
| **Build 构筑** | 捕获的鱼提供可叠加的能力，玩家逐步形成自己的流派 |
| **增量养成** | 🔴 Q2 —— 是否含离线收益 |
| **背包管理** | 空间有限，捕获即取舍，形成局内决策 |

### 1.3 核心体验目标

- **紧张**：弹幕密布时的走位压力 —— 来自负面情绪
- **治愈**：捕获成功时的柔和反馈、生物发光、缓慢摇摆 —— 来自正面情绪
- **取舍**：背包满了要丢谁？能力要叠哪个？—— 来自背包限制
- **领悟**：越深越接近真相，情绪不只是资源，而是被忽视的「人」

> 设计支点：**弹幕的「压迫感」与治愈的「柔软感」必须同时存在**。负面情绪鱼的弹幕要有压迫力，但美术与音效不能凶恶 —— 它们也是「被忽视的孩子」，只是变成了攻击性的样子。

## 2. 阵营与角色 ✅

五大阵营构成全部角色关系。

| 阵营 | 身份 | 代表什么 | 与玩家的关系 |
| --- | --- | --- | --- |
| **玩家** | 人类群体的化身 | 幸存的人类 | —— |
| **正面情绪鱼** | 小鱼（暖色 / 生物光） | 人类未被磨灭的正面情绪 | **友军 + 资源**：捕获后获得其能力 |
| **负面情绪鱼** | 小鱼（暗色 / 尖锐） | 人类的恶意与被压抑的负面情绪 | **敌人**：发射弹幕攻击玩家，需被净化 |
| **鲸鱼** | 巨物 | 人类积压情绪的聚合体 | **终极目标**：最终进入其体内 |
| **商人** | 中立 NPC | 在废墟中做生意的存在 | **供给方**：出售扩容与升级道具 |

### 2.1 关系图

```
                    ┌──────────────┐
                    │   鲸鱼       │  人类积压情绪的聚合体
                    │  （终局）     │  ← 最终进入其体内
                    └──────┬───────┘
                           │ 情绪从鲸体逸散
              ┌────────────┴────────────┐
              ↓                         ↓
     ┌────────────────┐        ┌────────────────┐
     │  正面情绪鱼     │        │  负面情绪鱼     │
     │  人类正面情绪   │        │  人类恶意       │
     └───────┬────────┘        └───────┬────────┘
             │ 捕获                    │ 净化
             ↓                         ↓
        ┌────────────────────────────────────┐
        │            玩家（人类）             │
        │   捕获 → 能力叠加 / 售卖换金币      │
        └────────────────┬───────────────────┘
                         │ 金币
                         ↓
                  ┌──────────────┐
                  │    商人       │  扩容道具 / 升级道具
                  └──────────────┘
```

### 2.2 设计要点：敌人不是「坏人」

负面情绪鱼是**人类的恶意**，但世界观里它们同样是「被忽视之物」。
因此：

- 它们的攻击行为要有**理由感**（不是为了伤害而伤害）
- 净化不是「击杀」，而是**安抚**
- 净化成功的表现应是鱼体**由尖锐变柔和、由暗转亮**，而不是爆炸消失

> 这条直接影响 VFX 与音效的方向，美术接入时必须知道。

## 3. 核心循环

### 3.1 局内循环（一次下潜，约 3–8 分钟）

```
安全区出发 → 下潜
        ↓
   鱼群出现（正面 / 负面混编）
        ↓
  ┌──────────────────────────────────┐
  │  躲避负面鱼的弹幕                  │
  │  发射捕获弹 → 命中正面鱼 = 捕获     │
  │  发射捕获弹 → 命中负面鱼 = 净化     │
  └──────────────┬───────────────────┘
                 ↓
        背包是否已满？─ 是 → 只能丢弃或返航
                 │否
                 ↓
        生命是否为 0？─ 是 → 强制返航（🔴 Q1 相关）
                 │否
                 ↓
           继续向更深处下潜
                 ↓
              返航结算
```

### 3.2 局外循环（安全区，约 1–3 分钟）

```
结算本次收获
    ↓
┌─────────────────────────────────────┐
│  ① 拆解鱼 → 提取能力 → 能力叠加升级   │
│  ② 售卖鱼 → 获得金币                  │
│  ③ 用金币向商人买背包扩容 / 升级道具   │
│  ④ 调整能力配置，准备下次下潜          │
└─────────────────────────────────────┘
```

**关键设计**：捕获的鱼是「能力」和「金币」的**同一来源**，玩家必须二选一 —— 拆解成能力，还是卖掉换钱。这构成局外循环的核心张力。

### 3.3 长线循环（章节推进）

```
完成本章情绪目标 → 解锁更深海域 → 更深的鱼种与更强的能力
        ↓                                    │
        └──────────── 数值与操作双向成长 ──────┘
                       ↓
            进入鲸鱼体内 → 找回四大情绪 → 结局
```

## 4. 战斗系统

### 4.1 玩家操作 🔴 Q1

🔴 **待确认**：玩家在弹幕中的主要动作是「躲」还是「打」？

| 方案 | 描述 | 优点 | 风险 |
| --- | --- | --- | --- |
| **A. 双向混合** 💡 | 一边闪避负面鱼的弹幕，一边持续发射捕获弹 | 最贴弹幕游戏手感，操作有深度 | 移动端双摇杆操作门槛偏高 |
| **B. 躲避为主** | 全程只走位，捕获靠进入鱼身周围的判定圈 | 操作轻，适合休闲与移动端 | 长时间容易单调 |
| **C. 射击为主** | 站桩输出为主，走位为辅 | 打击感强 | 弹幕压迫感弱 |

💡 **建议方案 A**，并把操作简化为：
- **移动**：单摇杆 / WASD + 鼠标
- **捕获弹**：自动索敌发射（玩家只需控制方向与时机），或用「点按方向键朝该方向发射」

这样既保留弹幕手感，又不需要双摇杆。

### 4.2 统一的核心动作：捕获弹

**捕获与净化共用同一套操作** —— 玩家只发射一种「捕获弹」，命中目标后按目标类型产生不同结果：

| 命中目标 | 结果 | 表现 |
| --- | --- | --- |
| 正面情绪鱼 | **捕获** | 鱼被光网包裹，收入背包 |
| 负面情绪鱼 | **净化** | 鱼由尖锐变柔和、由暗转亮，消散为「情绪结晶」 |

> 设计理由：单一操作降低学习成本；且「同一发子弹，对友军是拥抱，对敌人是安抚」在叙事上高度统一 —— **玩家从头到尾只做一件事：把情绪接住。**

### 4.3 捕获条（核心张力）

捕获不是即时的，而是需要**持续命中**：

```
捕获弹命中 → 目标身上累积「捕获条」
捕获条满 → 捕获 / 净化成功
捕获条随时间衰减 → 中断则进度倒退
```

- 正面鱼会**躲避**（越稀有躲得越快）
- 负面鱼会**反击**（捕获条未满时仍持续发射弹幕）
- 同时捕获多只 → 效率高但风险大

这条机制是战斗深度的核心来源，也是「背包满了要丢谁」之外的第二个决策点。

### 4.4 能力叠加 ✅

捕获正面鱼后，玩家获得它的**能力**（非数值）：

| 能力类型 | 示例来源 | 效果 |
| --- | --- | --- |
| 移动类 | 飞鱼、旗鱼 | 提升下潜/移动速度 |
| 防御类 | 鹦鹉螺、海龟 | 提升生命 / 抗弹幕时间 |
| 输出类 | 电鳗、河豚 | 提升捕获弹伤害 / 捕获条积累速度 |
| 辅助类 | 灯笼鱼、鮟鱇 | 提升视野、显示稀有鱼位置 |
| 特殊类 | 鲸类碎片 | 大幅提升全局效率 |

**叠加规则**：
- 同一鱼重复捕获 → 该能力**升级**（Lv1 → Lv2 → Lv3 …）
- 不同能力可**同时生效**，但有**装备栏上限** 🔴 待确认（建议 3–5 个生效槽）
- 升级消耗：同名鱼 + 情绪结晶

### 4.5 生命与失败 🔴

🔴 **待确认**：被弹幕击中会怎样？

💡 **建议**：
- 玩家有**生命值**（如 3–5 点 / 或一条血条）
- 被击中扣血 + 短暂无敌帧
- 生命归零 → **强制返航**，本次捕获的鱼**保留**，但失去继续下潜的机会
- **不做「掉落背包」的惩罚** —— 本作是治愈向，惩罚过重会破坏情绪基调

## 5. 背包系统 ✅

### 5.1 空间规则

| 项目 | 规则 |
| --- | --- |
| 容量单位 | 「格」 |
| 初始容量 | 💡 建议 12 格 |
| 鱼的占格 | 按体型与稀有度分 1 / 2 / 3 / 4 格 |
| 上限 | 💡 建议 60 格 |

**占格映射**：

| 稀有度 | 占格 | 逻辑 |
| --- | --- | --- |
| 常见 | 1 格 | 小、轻、多 |
| 稀有 | 2 格 | —— |
| 史诗 | 3 格 | —— |
| 传说 | 4 格 | 大、重、独占 |

> 稀有度越高越占地方 —— 玩家背包会被「珍贵但笨重」的鱼塞满，被迫在价值与容量之间取舍。

### 5.2 背包满时的处理 💡

建议提供三种出口，避免玩家卡死：

1. **现场丢弃**：手动丢弃背包内的鱼（丢弃后消失）
2. **强制返航**：结束本次下潜，回安全区结算
3. **紧急售卖** 🔴 待确认：是否允许在局内直接卖鱼换金币（会削弱背包压力，建议不做）

### 5.3 扩容

- 来源：**商人处购买扩容道具**（世界观内的合理包装：如「更结实的网」「鲸骨编织的背篓」）
- 节奏：随剧情推进解锁更高档位，避免玩家一次性买满
- 💡 建议每章解锁 2–3 次扩容机会，每次 +4 格

## 6. 经济与商店

### 6.1 货币

| 货币 | 来源 | 用途 |
| --- | --- | --- |
| **金币** | 售卖鱼 | 扩容、道具、常规升级 |
| **情绪结晶** | 净化负面情绪鱼 | 能力升级（更稀有的资源） |

> 双货币设计意图：捕获走「金币」线，净化走「结晶」线，让**友善与战斗两条行为路径都有回报**，避免玩家只挑一条路走。

### 6.2 商人

| 项目 | 设定 |
| --- | --- |
| 位置 | 安全区 / 章节入口 |
| 形态 | 🔴 待确认（人形？机械？被驯化的生物？） |
| 出售 | 背包扩容道具、能力升级材料、消耗品 |
| 收购 | 玩家售卖的鱼 |

💡 **建议**：商人本身也是「被忽视之物」的一种 —— 比如一台仍在运行的自动贩卖机，或一个穿着潜水服的旧玩偶。这样它与世界观自洽，而不是一个突兀的功能性 NPC。

## 7. 关卡与剧情推进 🔴 Q3 / Q4

### 7.1 章节结构 🔴

🔴 **待确认**：世界观文档中「四头鲸鱼分落四大洋」的设定是否延续？

| 方案 | 描述 |
| --- | --- |
| **A. 四洋四鲸** | 太平洋 / 大西洋 / 印度洋 / 北冰洋各一头鲸，各成一章，四大情绪分别镇守其中 |
| **B. 一鲸四域** | 所有积压情绪聚成唯一一条巨鲸，四大情绪是它体内的四个区域，依次找回 |
| **C. 其他** | 由主策指定 |

### 7.2 四大情绪 🔴 Q4

🔴 **待确认**：「被漠视的四大情绪」具体是哪四种？

| 候选 | 内容 | 倾向 |
| --- | --- | --- |
| A | 喜 / 怒 / 哀 / 惧 | 经典四分法，通用性强 |
| B | 爱 / 怒 / 哀 / 惧 | 以「爱」替「喜」，更贴治愈内核 |
| C | 孤独 / 愤怒 / 悲伤 / 恐惧 | 现代语境，更贴「被漠视」的主题 |

### 7.3 结局 ✅

玩家进入鲸鱼体内 → 找回四大情绪 → **鲸鱼消散，陆地恢复**。

💡 建议在此基础上增加**情绪呈现**：鲸鱼消散不该是「爆炸」，而是缓慢的、温柔的解体 —— 海水退去，城市从水下浮起，被遗忘之物以光的形式回到人间。这与「治愈」基调一致。

## 8. 数值框架 💡

> 以下为建议初始值，需在原型阶段验证后调整。

- 🔴 Q2 若保留离线收益，**离线与在线结算必须共用同一套公式**
