## 0. 这份文档怎么用

### 0.1 四种颗粒度，按阶段递进

不要一开始就写到最细。按开发阶段选颗粒度，否则会返工：

| 阶段 | 颗粒度 | 交付物 | 触发时机 |
| --- | --- | --- | --- |
| P0 立项 | **一页纸** | 三条叙事支柱 + 一句话故事 + 情绪曲线 | 现在 |
| P1 预制作 | **节拍表** | 四章节拍表 + 角色小传 + 术语表 | 本章程 1—4 节填完 |
| P2 单图验证 | **单章全脚本** | 第一章全部场景脚本 + 对白 + 演出表 | 第一张图开工前 |
| P3 量产 | **全量脚本** | 四章全部脚本、全量对白表、图鉴文本 | 四张图并行时 |

**当前应锁定在 P1。** 四张图并行前必须完成 P2。

### 0.2 与其他文档的边界

| 文档 | 负责 | 不负责 |
| --- | --- | --- |
| `world-setting.md` | 世界怎么运转、为什么 | 玩家具体经历什么 |
| `game-design.md` | 玩法规则、数值 | 玩家为什么在意 |
| **本文档** | **玩家经历什么、按什么顺序经历、如何呈现** | 数值、系统实现细节 |
| GDD v1.0 | 全项目总基线 | —— |

同一个设定**只在一处写死**，其他文档引用。发现重复描述时，以本文档为准。

### 0.3 维护规则

- 每次改动在文末「修订记录」加一行，写清改了什么、为什么
- 术语一旦定稿进第 2.4 节术语表，全文严格统一，包括代码变量名
- 章节编号即剧情编号，后续对白表、演出表、存档字段全部引用同一个编号体系

## 1. 参考坐标：成熟作品是怎么做的

框架不是凭空造的。以下是从公开的叙事设计文档模板与已发行独立游戏的实际结构里归纳出来的。

### 1.1 通用骨架（NDD 十二段）

业内通用的叙事设计文档（Narrative Design Document）通常包含：

| # | 通用章节 | 作用 |
| --- | --- | --- |
| 1 | 执行摘要 Executive Summary | 题材、基调、一句话钩子、对标作品 |
| 2 | 故事总览 Story Overview | 完整剧情梗概、幕结构、结局变体、主题陈述 |
| 3 | 世界圣经 World Bible | 完整设定、历史、势力、语言风格指南 |
| 4 | 角色档案 Character Profiles | 每个角色一页、弧光、关系图 |
| 5 | 任务设计 Quest Design | 主线链、支线索引、势力线 |
| 6 | 对白系统 Dialogue Systems | 树结构、配音预算、分支逻辑、标志位登记 |
| 7 | 环境叙事 Environmental Narrative | 地点叙事、收集物计划 |
| 8 | 叙事度量 Narrative Metrics | 字数、配音时长、分支复杂度、覆盖图 |
| 9 | 演出与呈现 Presentation | 过场分级、镜头、音频提示 |
| 10 | 系统对接 Implementation | 触发器、数据结构、本地化 |
| 11 | 范围管理 Scope Management | 砍什么、保什么、最小可交付 |
| 12 | 验收标准 QA | 可跳过、可重看、不阻塞 |

### 1.2 值得直接借用的具体做法

| 来源做法 | 出处类型 | 怎么用在本作 |
| --- | --- | --- |
| **叙事支柱 ≤ 3 条，每条必须绑定一个玩法机制** | 独立游戏叙事设计框架 | 见 1.3，本作的支柱直接对应「净化/装备/下潜」三个动作 |
| **角色小传压缩到每人一页** | 单人开发者叙事指南 | 六人团队更该压，避免 10 页设定没人看 |
| **启示阶梯：小真相反转 → 更大真相 → 最终反转** | 叙事设计师技能框架 | 本作已有「五层打捞」雏形，但需与 GDD 的中段真相合并 |
| **环境叙事模板：空房间 / 前后对比 / 不可靠环境** | 单人开发者叙事指南 | 本作零过场预算，环境叙事是主力载体 |
| **对白量按「条数 × 平均字数」倒推工期** | 叙事度量 | 见第 12 节，先定预算再动笔 |
| **标志位登记表（Flag Registry）** | 对白系统设计 | 记忆回看、情绪找回状态都靠它 |
| **叙事流程图记号法**（方框=场景，菱形=选择，花括号=条件） | 叙事流程规范 | 用于第 4 节节拍表 |
| **「最小可行故事」概念** | 单人开发者叙事指南 | 见本文第 5 节 |
| **叙事边界（不宣称什么、不做什么）** | GDD v1.0 第 14.6 节 | 已写得很好，直接继承并扩充 |

### 1.3 参考作品与可借鉴点

| 作品 | 借什么 | 不借什么 |
| --- | --- | --- |
| **GRIS** | 用颜色与动作承载全部情绪，零文字叙事 | 本作仍需要文字，玩家要理解"被忽视"的机制 |
| **Spiritfarer** | 告别主题的"陪伴式"任务设计，每个角色一段收束 | 本作不做角色群像养成，规模不允许 |
| **Hollow Knight** | 碎片化环境叙事 + 图鉴文本逐步补全世界真相 | 本作难度不做硬核，叙事不能依赖玩家深挖 |
| **ABZÛ / 深海迷航** | 水下空间的情绪节奏、生物光的视觉语言 | —— |
| **Outer Wilds** | 用「重复游玩」与已通关后重访兼容（本作已有"重访记忆"入口） | 本作不做时间循环结构 |
| **《去月球》《艾迪芬奇的记忆》** | 用日常物件（怀表、信件、餐桌）承载记忆 | —— |

## 2. 模块一：叙事总纲

**目的**：给全组一个可复述的"立意"，让美术、程序在没有你的时候也能判断某个设计对不对。

**必填字段**：

| 字段 | 要求 | 现状 |
| --- | --- | --- |
| 一句话故事 | ≤ 60 字，能背下来 | ⏳ 待写（GDD 有素材） |
| 十秒电梯稿 | ≤ 150 字，给发行/评委听 | ⏳ 待写 |
| **三条叙事支柱** | 每条必须绑定一个玩法机制，见下 | ⏳ 待定 |
| 主题陈述 | 回答"这个故事在讲什么"，不是情节 | 🟡 有雏形（「治愈来自被看见」） |
| 玩家情绪曲线 | 各章节玩家应该感觉到什么，一句话 | ⏳ 待写 |
| 叙事边界 | 明确不做什么、不宣称什么 | 🟢 已有一版（GDD 14.6），需扩充 |
| 对标作品 | 3—5 个，说明各借什么 | 🟡 见本文 1.3，待团队确认 |

**三条叙事支柱的预定形态**（需你确认）：

| 支柱 | 绑定的玩法机制 | 玩家应该感觉到的 |
| --- | --- | --- |
| 被忽视之物不会消失，只会上升 | 净化：敌鱼不消灭，转为伙伴 | 「我做的事不是杀死，是接住」 |
| 陪伴即回应 | 四槽伙伴：鱼在身边参与战斗 | 「我不是一个人在下面」 |
| 抵达比变强更重要 | 能力解锁下潜深度 | 「成长的意义是能去更远的地方」 |

> 检验标准：任何一条剧情、一个演出、一句对白，如果**不能**服务于这三条中的至少一条，砍掉。

**交付物**：一页纸，全组群里置顶。

## 4. 模块三：角色档案

**目的**：让每个角色说话时能被认出来。

**每人一页，字段固定**：

```
【角色名】
定位：          （在剧情中的功能）
一句话动机：    （他想要什么）
创伤/缺陷：     （他缺什么）
弧光：          （从 A 变成 B，一句话）
声线：          （词汇水平、说话长度、口头习惯）
代表台词 ×3：
与其他角色关系：
出没章节：
视觉要点：
```

**需要建档的角色**：

| 角色 | 现状 | 备注 |
| --- | --- | --- |
| 拾海人（主角） | 🟡 有定位，缺性格与弧光 | ✅ 形式已定：**沉默、有名字、灾后出生、没见过陆地**（D4 + Q7）。**缺**：他自己的那段"没说出口的话"是留给谁的（Q14） |
| 阿渡（商人） | 🟡 有定位，缺声线 | ✅ 定位升级：**他是玩家的声音**（D4 带来的角色）。可据 GDD 14.1 的台词提炼声线 |
| 缄泪之壳 | 🟢 有形象 + 胜利演出 + 对白 | 需补"它原本是什么" |
| 惊影巡游者 | 🟢 同上 | 同上 |
| 怒潮钳冠 | 🟢 同上 | 同上 |
| 无回应之眼 | 🟢 同上 | 同上 |
| 鲸鱼（主鲸） | 🟡 已定形式，缺内容 | ✅ **有意志，但不说人话**（Q5）。表达手段限定为：回声、光、纹样、身体反应。**禁止**给它一句人类对白（现有 14.3 的「吃饭了，回家吧」是**记忆里的声音**，不是鲸在说话，须在文档中写清区别） |

### 4.1 四组「未出口的话」怎么用（D6 修正版）

> **修正说明（2026-09-29）**：D6 原定「三段陌生人 + 最后一段落在主角自己身上」。
> 用户 Q14 答复推翻了后半段 —— **第四段也不是主角的**，而是「过去世界的居民积压在心底、从未表达出来的情绪」。
> 修正后的结构文本上更统一（四段性质一致），代价是**主角的情感落脚点必须另找**，见 4.3。

四组的主体**全部是过去世界的普通居民**。每组按「三段碎片 → 一句话」呈现：

| 组 | 章节 | 情绪的现场（三段碎片） | 拼合后浮现的那句话 |
| --- | --- | --- | --- |
| 一 | 悲伤 · 泪潮旧居 | 拼合三段未完成的告别（GDD 13.1） | 那个人最终没能说出口的**告别** |
| 二 | 恐惧 · 回响暗廊 | 点亮三座求助信标（GDD 13.1） | 那个人最终没能喊出的**求助** |
| 三 | 愤怒 · 灼流腔室 | 找回被反复覆盖的边界声明（GDD 13.1） | 那个人最终没能说出的**「不」** |
| 四 | 孤独 · 远灯静海 | 将三处孤立信号接到同一频道（GDD 13.1） | 那个人最终没能问出的**「你在吗」** |

> **这个结构对齐很关键。** GDD 13.1 的每章任务本来就是「三段式」，而本框架原先写的是「四段告别」，两者此前是**两套互不对应**的东西。
> 现在统一为一套：**每章三段碎片 → 拼出该章的一句话 → 全作共四句话**。
> 好处是 GDD 已有的 12 个任务节点**不需要重写**，只需补上「它们最终指向哪句话」。
> 三段碎片与那句话的具体关系（拼图式 / 线索式）待定，见 Q18。

**四句话的性质（必须写死）**：

- 全部来自**普通人**，不给英雄、不给特殊身份。重量来自「普通」，不来自「悲壮」
- 全部是**没有被说出口的**，而不是「说错了」或「来不及说」。差别在于：玩家不需要替他们纠正错误，只需要**让话被听见**
- 四句话的**接收者各不相同**（一个逝去的人、一个离开的人、一个再也不会回来的人、一个不知道还在不在的人）。具体身份待定（Q17）
- 顺序不可调。情绪强度是**逐章递进**的，把孤独放最前会一路泄掉后面

### 4.2 据点居民与结局的联动

选"少量氛围居民"其实**顺带解决了一个问题**：GDD 14.5 的结局里有「有人修桥，有人晾晒物品，有人在新露出的路口等待同伴」这一组群像镜头。
如果据点从头到尾只有阿渡一个人，这组镜头会显得**凭空冒出来** —— 观众没见过这些人。
有 3—5 个居民在据点日常出现，结局的群像就是**回收**，而不是**介绍**。

**代价**：3—5 个角色 = 3—5 套美术资产 + 待机动画 + 约 15—30 条氛围台词。需要在美术排期里明确列出来，不要临时加。

**顺带损失**：据点的荒凉感会减弱。第四章的「孤独」主题因此要**更多由关卡空间承担**，不能再依赖"据点只有我一个人"来铺垫。

**关系图**：一张图，标出谁认识谁、谁知道什么。

### 4.3 主角的落脚点（D6 修正带来的必答问题）

四段都是**别人的**话，而主角又是**沉默的** —— 那主角的情感出口在哪？

答案不是「给主角也补一段话」（那是 D6 旧版的思路），而是以下三条同时成立：

1. **他是最后一个听的人。** 灾后出生、从未见过陆地的他，听的是**别人的乡愁**。这不是缺憾，是设定本身的力量：他不是失去者，是**继承者**
2. **他用动作回应。** GDD 14.6 已定原则：「主角不需要突然成为心理治疗师。对话保持具体的人和事，**用行动完成回应**」。第 7 节场景卡的「主角动作反应」字段就是这条原则的落点
3. **弧光写在动机上，不写在台词上。** GDD 3.4 已写：「其动机从修复浮岛，逐渐扩展为理解旧世界并帮助鲸鱼释放积压」。起点是**功利**（浮岛浮力减弱，他要活下去），终点是**理解**（他想知道为什么）—— 这就是完整弧光，不需要台词点题

> ⚠️ 由此推出一条写作纪律：**不要让阿渡替主角说「我懂了」这类总结句。**
> 主角的表态永远停在动作层面，观众自己会读出来。这是「留白是设计，不是遗漏」的具体执行方式。

**闭环验证**：结局最后一句台词原本是主角说的「先回家。然后，再去看看。」（GDD 14.5）。
按 D4 该句已删。现在有了 4.3 的解释，这个删除**不只是合规**，而是结构上的必然 ——
主角不说话，所以最后一句落回环境（路牌、海面、门），而**替所有人落地**这个动作由他完成。这比让他说一句漂亮话要重得多。

## 5. 模块四：剧情结构

**目的**：把故事切成可施工的段落，并明确玩家在每个节点知道什么。

### 5.1 认知阶梯表（本作的核心工具）

本作的悬念不是"谁是坏人"，而是**"玩家以为自己懂，其实还差一层"**。所以每章都要标出玩家认知与真相的距离：

| 节点 | 玩家以为 | 实际上 | 通过什么手段揭示 |
| --- | --- | --- | --- |
| 开场 | 鱼群迁徙，我要修好浮岛 | —— | 商人一句提示 |
| 第一章末 | 鱼身上带着人类的东西 | 鱼曾是人类记忆 | 首领战后演出 |
| 第二章末 | 有些请求我没听见 | —— | 求助信标事件 |

> **勘误（2026-09-29）**：本节此前把鲸的结构写成了「world-setting 四头 vs GDD 一头」，这是读漏。

### 6.1 ⚠️ 决策引发的连锁修改（必须同步处理）

**「沉默主角」与 GDD v1.0 现有文本冲突。** GDD 14.1 与 14.5 里主角是有台词的：

| 位置 | 现有文本 | 处理 |
| --- | --- | --- |
| 14.1 开场 | 玩家：「我把它们带回来。」 | ❌ 删除。改为阿渡发问、玩家以动作作答（系紧绑带、望向鱼群游去的方向） |
| 14.5 结局 | 玩家：「先回家。然后，再去看看。」 | ❌ 删除。改为阿渡问「想好往哪里走了吗？」，玩家看向伙伴与浮岛，切路牌，上结束字幕 |

**沉默主角反而给了两个好处**：

1. 阿渡从"功能 NPC"升级为**玩家的声音** —— 他说的每句话都在替玩家表态。这需要在他的角色档案里明确写死
2. 结局最后一句台词落回环境（路牌、海面、门）而不是人嘴里，**收束更克制、更契合「治愈不靠说出来」的基调**

**边界（不能越线）**：沉默 ≠ 无表情。主角必须在每个节拍有**明确的可读动作反应**，否则会显得像个空壳。第 7 节的场景卡新增一个必填字段：**主角动作反应**。

- [ ] 无任何一段演出阻塞战斗节奏（B 级 ≤ 12 秒硬上限）
- [ ] 全量文本无心理学术语与说教句式
- [ ] 每条对白都能被非策划读者理解（找组外的人读一遍）
- [ ] 术语表 100% 覆盖，全文无同义混用
- [ ] 每个场景都绑定了一个可判定的退出条件
- [ ] 所有文本 ID 唯一且符合命名规则
- [ ] 四章认知阶梯逐级递进，不存在玩家提前猜到关键真相的路径
- [ ] 结局不违背「叙事边界」中列出的不可变量
- [ ] 未通关玩家不会接触到结局文本（无剧透泄漏）

## 17. 待确认问题清单（第四批）

第三批（Q14—Q16）已全部答复，结论见 D6 修正与 D9—D10。
**Q14 的答案修正了 D6**（四段主体全部为过去居民，主角不占一段），连带解决了 4.3 的主角落脚点问题。

| # | 问题 | 为什么必须定 | 阻塞 |
| --- | --- | --- | --- |
| **Q17** | **四组「未出口的话」是四个具名的人，还是四类人群？** | 直接决定要不要给人物起名、写小传。具名 → 情感更具体、四句话有明确的"谁在说"，但要写 4 页人物设定；不具名 → 省成本，但四句话会失去"具体的人"这个重量，而本作的主题恰恰是「具体的人和事」（GDD 14.6） | 模块三（角色档案）、模块五（全章脚本） |
| **Q18** | **每章的三段碎片与最后那句话是什么关系？** | 两种做法差别很大：**拼图式**（三段拼起来就是那句话）／**线索式**（三段是三个人的痕迹，拼合后浮现出其中一个人的话）。这决定任务奖励的呈现、首领战的触发逻辑与演出写法 | 模块七（任务设计）、模块九（演出） |
| **Q19** | **主角的「动作回应」母题是什么？** | 沉默主角的唯一情感出口。需要一个可复用的动作语汇（伸手又收回 / 停顿半秒 / 灯闪一次 / 先看伙伴再看前方），否则 20 多个场景的「主角动作反应」会互相重复、失去表意能力 | 模块五（全章脚本）、模块九（演出） |
| **Q20** | **阿渡的来历是什么？** | 他是「玩家的声音」（D4 的连带定位），但台词的**立场**取决于他为什么懂这些：他是幸存者？灾后拾荒者？还是他自己也是「没说出口的人」之一？这决定他全程的口吻是"过来人"还是"同样在学" | 模块三（角色档案）、模块六（对白） |
