### 0.1 四种颗粒度，按阶段递进

不要一开始就写到最细。按开发阶段选颗粒度，否则会返工：

| 阶段 | 颗粒度 | 交付物 | 触发时机 |
| --- | --- | --- | --- |
| P0 立项 | **一页纸** | 三条叙事支柱 + 一句话故事 + 情绪曲线 | 现在 |
| P1 预制作 | **节拍表** | 四章节拍表 + 角色小传 + 术语表 | 本章程 1—4 节填完 |
| P2 单图验证 | **单章全脚本** | 第一章全部场景脚本 + 对白 + 演出表 | 第一张图开工前 |
| P3 量产 | **全量脚本** | 四章全部脚本、全量对白表、图鉴文本 | 四张图并行时 |

**当前应锁定在 P1。** 四张图并行前必须完成 P2。

### 0.2 与其他文档的边界

| 文档 | 负责 | 不负责 |
| --- | --- | --- |

## 1. 参考坐标：成熟作品是怎么做的

框架不是凭空造的。以下是从公开的叙事设计文档模板与已发行独立游戏的实际结构里归纳出来的。

### 1.1 通用骨架（NDD 十二段）

业内通用的叙事设计文档（Narrative Design Document）通常包含：

| # | 通用章节 | 作用 |
| --- | --- | --- |
| 1 | 执行摘要 Executive Summary | 题材、基调、一句话钩子、对标作品 |
| 2 | 故事总览 Story Overview | 完整剧情梗概、幕结构、结局变体、主题陈述 |
| 3 | 世界圣经 World Bible | 完整设定、历史、势力、语言风格指南 |
| 4 | 角色档案 Character Profiles | 每个角色一页、弧光、关系图 |
| 5 | 任务设计 Quest Design | 主线链、支线索引、势力线 |
| 6 | 对白系统 Dialogue Systems | 树结构、配音预算、分支逻辑、标志位登记 |
| 7 | 环境叙事 Environmental Narrative | 地点叙事、收集物计划 |
| 8 | 叙事度量 Narrative Metrics | 字数、配音时长、分支复杂度、覆盖图 |
| 9 | 演出与呈现 Presentation | 过场分级、镜头、音频提示 |
| 10 | 系统对接 Implementation | 触发器、数据结构、本地化 |
| 11 | 范围管理 Scope Management | 砍什么、保什么、最小可交付 |
| 12 | 验收标准 QA | 可跳过、可重看、不阻塞 |

### 1.2 值得直接借用的具体做法

| 来源做法 | 出处类型 | 怎么用在本作 |
| --- | --- | --- |
| **叙事支柱 ≤ 3 条，每条必须绑定一个玩法机制** | 独立游戏叙事设计框架 | 见 1.3，本作的支柱直接对应「净化/装备/下潜」三个动作 |
| **角色小传压缩到每人一页** | 单人开发者叙事指南 | 六人团队更该压，避免 10 页设定没人看 |
| **启示阶梯：小真相反转 → 更大真相 → 最终反转** | 叙事设计师技能框架 | 本作已有「五层打捞」雏形，但需与 GDD 的中段真相合并 |

| **叙事边界（不宣称什么、不做什么）** | GDD v1.0 第 14.6 节 | 已写得很好，直接继承并扩充 |

## 2. 模块一：叙事总纲

**目的**：给全组一个可复述的"立意"，让美术、程序在没有你的时候也能判断某个设计对不对。

**必填字段**：

| 字段 | 要求 | 现状 |
| --- | --- | --- |
| 一句话故事 | ≤ 60 字，能背下来 | ⏳ 待写（GDD 有素材） |
| 十秒电梯稿 | ≤ 150 字，给发行/评委听 | ⏳ 待写 |
| **三条叙事支柱** | 每条必须绑定一个玩法机制，见下 | ⏳ 待定 |
| 主题陈述 | 回答"这个故事在讲什么"，不是情节 | 🟡 有雏形（「治愈来自被看见」） |
| 玩家情绪曲线 | 各章节玩家应该感觉到什么，一句话 | ⏳ 待写 |
| 叙事边界 | 明确不做什么、不宣称什么 | 🟢 已有一版（GDD 14.6），需扩充 |
| 对标作品 | 3—5 个，说明各借什么 | 🟡 见本文 1.3，待团队确认 |

**三条叙事支柱的预定形态**（需你确认）：

| 支柱 | 绑定的玩法机制 | 玩家应该感觉到的 |
| --- | --- | --- |
| 被忽视之物不会消失，只会上升 | 净化：敌鱼不消灭，转为伙伴 | 「我做的事不是杀死，是接住」 |
| 陪伴即回应 | 四槽伙伴：鱼在身边参与战斗 | 「我不是一个人在下面」 |
| 抵达比变强更重要 | 能力解锁下潜深度 | 「成长的意义是能去更远的地方」 |

> 检验标准：任何一条剧情、一个演出、一句对白，如果**不能**服务于这三条中的至少一条，砍掉。

**交付物**：一页纸，全组群里置顶。

**每人一页，字段固定**：

```
【角色名】

一句话动机：    （他想要什么）

弧光：          （从 A 变成 B，一句话）
声线：          （词汇水平、说话长度、口头习惯）
代表台词 ×3：
与其他角色关系：
出没章节：
视觉要点：
```

### 4.1 四组「未出口的话」：四类人群 × 三个人（Q17 + Q18 定稿）

四组的主体**不是四个具名角色，而是四类人群** —— 每一类人都被同一种情绪以不同方式影响过。

> **为什么用人群而不是具名角色**：这场灾难是**集体的忽视**造成的，不是某一个人的过失；而悲伤、恐惧、愤怒、孤独本来就是普遍的人类经验。
> 用人群承载，情绪的量级才对得上。GDD 3.1 对「余声」的定义也是「**人类**没有被听见的话」—— 是人类的，不是某一个人的。

**每章的结构 = 三个不同的人 × 同一种情绪的不同影响 → 拼出一句共有的话**

| 组 | 章节 | 三个人（同一情绪的三种影响） | 共有的那句话 |
| --- | --- | --- | --- |
| 一 | 悲伤 · 泪潮旧居 | 失去居所的人 / 失去关系的人 / 失去了自己的人 | 「**告别**」 |
| 二 | 恐惧 · 回响暗廊 | 守着不肯睡的人 / 不敢开门的人 / 反复确认门锁的人 | 「**求助**」 |
| 三 | 愤怒 · 灼流腔室 | 摔东西的人 / 自责的人 / 一直说「没事」的人 | 「**不**」 |
| 四 | 孤独 · 远灯静海 | 反复拨号的人 / 守着灯的人 / 把灯关掉的人 | 「**你在吗**」 |

> 三个人物是**处境切片**，不是具名角色 —— 不需要名字与人物小传，只需要一个能一眼看懂的处境。

#### 线索式呈现（Q18 定稿）

三段碎片**不是同一句话的三个碎片**，而是**三个不同的人留下的三处痕迹**。
它们的价值不在于拼成一个完整的句子，而在于让玩家看见：**同一种情绪，在不同人身上长成了不同的样子。**

玩家收集完三段后，浮现的不是「某个人说的话」，而是**这一类人一直在说的同一句话** —— 只是从没被听完过。

> 好处：玩家不是在**解谜**，而是在**认出** —— 他认出的是自己或身边人的样子。
> 这也是「不做反转式叙事」的落地方式：真相不靠骗，靠认得。

**三处痕迹的差异必须看得见**（写作纪律）：

| 要差异化的 | 怎么差异 |
| --- | --- |
| 物件 | 三个人各留一件东西，材质与用途完全不同（一只没人穿的鞋 / 一段没播完的录音 / 一扇始终没关的门） |
| 动作 | 三个人的姿态一眼能分辨（在等 / 在躲 / 在收拾） |
| **一样的缺失** | 缺的必须是**同一样东西** —— 这正是「同一种情绪」的证据 |
| ❌ 禁止 | 写成「同一个人说了三遍」，或三个人的痕迹其实是同一件物的碎片 |

#### 四句话的性质（必须写死）

- 全部来自**普通人**，不给英雄、不给特殊身份。重量来自「普通」，不来自「悲壮」
- 全部是**没有被说出口的**，而不是「说错了」或「来不及说」。差别在于：玩家不需要替他们纠正错误，只需要**让话被听见**
- 顺序不可调。情绪强度是**逐章递进**的，把「孤独」放最前会一路泄掉后面
- **拼出四句话只是"看见"，还不是"正视"** —— 正视发生在首领战里，见 9.1

### 4.2 据点居民与结局的联动

选"少量氛围居民"其实**顺带解决了一个问题**：GDD 14.5 的结局里有「有人修桥，有人晾晒物品，有人在新露出的路口等待同伴」这一组群像镜头。
如果据点从头到尾只有阿渡一个人，这组镜头会显得**凭空冒出来** —— 观众没见过这些人。
有 3—5 个居民在据点日常出现，结局的群像就是**回收**，而不是**介绍**。

**代价**：3—5 个角色 = 3—5 套美术资产 + 待机动画 + 约 15—30 条氛围台词。需要在美术排期里明确列出来，不要临时加。

**顺带损失**：据点的荒凉感会减弱。第四章的「孤独」主题因此要**更多由关卡空间承担**，不能再依赖"据点只有我一个人"来铺垫。

**关系图**：一张图，标出谁认识谁、谁知道什么。

### 4.3 主角的落脚点（D6 修正带来的必答问题）

四段都是**别人的**话，而主角又是**沉默的** —— 那主角的情感出口在哪？

答案不是「给主角也补一段话」（那是 D6 旧版的思路），而是以下三条同时成立：

1. **他是最后一个听的人。** 灾后出生、从未见过陆地的他，听的是**别人的乡愁**。这不是缺憾，是设定本身的力量：他不是失去者，是**继承者**
2. **他用动作回应。** GDD 14.6 已定原则：「主角不需要突然成为心理治疗师。对话保持具体的人和事，**用行动完成回应**」。第 7 节场景卡的「主角动作反应」字段就是这条原则的落点
3. **弧光写在动机上，不写在台词上。** GDD 3.4 已写：「其动机从修复浮岛，逐渐扩展为理解旧世界并帮助鲸鱼释放积压」。起点是**功利**（浮岛浮力减弱，他要活下去），终点是**理解**（他想知道为什么）—— 这就是完整弧光，不需要台词点题

> ⚠️ 由此推出一条写作纪律：**不要让阿渡替主角说「我懂了」这类总结句。**
> 主角的表态永远停在动作层面，观众自己会读出来。这是「留白是设计，不是遗漏」的具体执行方式。

**闭环验证**：结局最后一句台词原本是主角说的「先回家。然后，再去看看。」（GDD 14.5）。
按 D4 该句已删。现在有了 4.3 的解释，这个删除**不只是合规**，而是结构上的必然 ——
主角不说话，所以最后一句落回环境（路牌、海面、门），而**替所有人落地**这个动作由他完成。这比让他说一句漂亮话要重得多。

### 4.3.1 主角的动作母题（Q19 定稿，可直接抄进场景卡）

沉默主角唯一的表达渠道是动作。但如果每个场景都重新设计动作，25 个场景会互相稀释、全部失效。
所以定一套**母题 + 变体**，母题反复出现，变体负责具体情境。

**主母题：伸手 —— 但从不真的碰到（逐章变化）**

| 章 | 动作 | 含义 |
| --- | --- | --- |
| 一 · 悲伤 | 伸手 → 停在半空 → **收回** | 「我还不敢」 |
| 二 · 恐惧 | 伸手 → 停在半空 → **不收回** | 「我开始愿意了」 |
| 三 · 愤怒 | 伸手 → **触到** | 「第一次真的碰到」 |
| 四 · 孤独 | 伸手 → 触到 → **松开** | 「我可以放下了」 |

> 全作用同一个动作的四种处理完成弧光，**不需要一句台词**。
> 而「不碰到」本身就是主题：**被忽视的东西需要的是被看见，不是被抓住。**

**副母题：灯 —— 只用于说「我在这里」**

灯是主角唯一的「发声器官」。它**不表达情绪，只表达存在**：有人来了，我在听。
第四章「远灯静海」的接续机制就是这条母题的机制化 —— 玩家用灯回应，对方才亮起来。

**动作语汇表**（其他场景从这里取，不要另造）：

| 语汇 | 用在哪 |
| --- | --- |
| 停顿半秒再上前 | 面对新的东西 |
| 先看伙伴，再看前方 | 犹豫时（支柱 2「陪伴即回应」的可见化） |
| 伸手，停在半空 | 想靠近但不确定 |
| 松开手 | 接受与放下 |
| 灯闪一次 | 回应（唯一"说话"方式） |
| 不回头 | 决定之后 |
| 蹲下，把一样东西放回原处 | 环境叙事的收尾动作 |

> **纪律**：除主母题的刻意复现外，**同一章内不要连续两个场景使用同一个语汇**。
> 另：主母题的四种处理**每章只能用一次**，用在首领战或该章情绪最重的那一场。

### 4.4 阿渡：唯一的幸存者（Q20 定稿）

**他是据点里唯一见过陆地的人。** 这一定位一次解决三个问题：

| 问题 | 阿渡的作用 |
| --- | --- |
| 主角不认识陆地，玩家也不认识 | 他是**旧世界词典** —— 玩家看到不认识的物件时，他报出名字。**但只报名字，不解释意义**（一解释就变成说教） |
| 沉默主角需要一张嘴 | 他是**玩家的声音**（D4 的连带定位），替玩家表态，但**只说到一半** |
| 主题需要一个活着的样本 | 四组「未出口的话」都属于**逝去的**人。阿渡是唯一一个**还活着、还能说、却选择不说**的人 |

**他自己也有一句没说出口的话。但全作不交代它是写给谁的。**

> 这是刻意的：四组未出口的话玩家都帮着「听完」了，只有阿渡的没有。
> 因为他还活着 —— **活人还有机会说，所以不必由玩家代为完成**。这是全作留给未来的唯一一个口子。
>
> 写作纪律：**可以让他差点说出口**（一次停顿、一句「算了」、一个转开的话头），但**永远不说出来**。

**口吻（禁止项）**：

- ❌ 不说教、不总结主题、不替玩家说「我懂了」
- ❌ 不用心理学术语（GDD 14.6 + 叙事边界）
- ✅ 只说**具体的事**：「那个东西叫门牌，每家一个，写着自己家的名字。」
- ✅ 可以不耐烦、可以走神、可以答非所问 —— 他是过来人，不是导游

**由此得到一条有用的叙事装置**：主角（和玩家）不认识旧世界的物件，阿渡认识。
所以「阿渡报出物件名字」可以承担大量世界观信息，而且**天然不说教** —— 他只是在说那是什么，不评价它意味着什么。
例：不说「这是被遗忘的亲情」，只说「那是张全家福。拍的时候人不齐。」

## 5. 模块四：剧情结构

**目的**：把故事切成可施工的段落，并明确玩家在每个节点知道什么。

### 5.1 认知阶梯表（本作的核心工具）

本作的悬念不是"谁是坏人"，而是**"玩家以为自己懂，其实还差一层"**。所以每章都要标出玩家认知与真相的距离：

| 节点 | 玩家以为 | 实际上 | 通过什么手段揭示 |
| --- | --- | --- | --- |
| 开场 | 鱼群迁徙，我要修好浮岛 | —— | 阿渡一句提示 |
| 第一章中 | 我在打怪物 | 它们是「被无视的东西」变的 | 三段线索拼合 |
| 第一章末 | 打碎它就好了 | 它只是把自己封起来了 —— 越打越硬 | 缄泪之壳：强攻无效，停下才开缝 |
| 第二章末 | 有些请求我没听见 | 它们一直在发，是我没回头 | 惊影巡游者：照住它才定得住 |
| 第三章末 | 恶意和情绪不是一回事 | 情绪需要出口，不需要压制 | 怒潮钳冠：给它方向才释放 |
| 第四章末 | 我在等回应 | 我一直也在被等 | 无回应之眼：回一次，它稳一分 |
| 结局 | 灾难是人类自己造成的 | —— | 四幅记忆画面 |

> 注意最后四行：**每章末的认知都发生在首领战里，不是靠台词说出来的。**
> 这是 Q18 的要求落点 —— 玩家不是被告知"要正视情绪"，而是**在玩法里不得不正视它**。

> **注意**：GDD v1.0 走的是"情绪理解"路线，`world-setting.md` 走的是"真相打捞五层"路线。**两者必须先合并成一套**（见第 6 节问题 Q1）。

### 5.2 节拍表

每章拆成若干节拍，每拍填：

| 字段 | 说明 |
| --- | --- |
| 编号 | 如 `C1-B03` |
| 节拍名 | 一句话 |
| 地点 | 引用世界圣经地理 |
| 出场角色 | |
| 情节目的 | 这一拍推进了什么 |
| 情绪目标 | 玩家应该感觉到什么 |
| 玩法交织 | 这一段玩家在玩什么（不能全是看） |
| 玩家获得的信息 | 新增认知 |
| 预估时长 | 分钟 |
| 关联演出 | 引用演出表编号 |

### 5.3 结局结构

✅ **已拍板（2026-09-29）：单一结局，线性主线，无剧情分支。**

| 字段 | 状态 |
| --- | --- |
| 结局数量 | ✅ **一个**。`world-setting.md` 的「打捞 / 留驻」双结局**作废** |
| 玩家选择 | ✅ **不存在影响走向的选择**。全部玩家看到同一个故事，差异只在节奏与顺序 |
| 结局演出分镜 | 🟡 GDD 14.5 有文字描述，缺分镜 |
| 通关后状态 | 🟢 已有「重访记忆」入口 |
| 结局不变量 | 🟢 GDD 14.6 写得很清楚（不复活逝者、不抹除伤痕） |

**这一决策带来的简化**：

- 不需要写分支逻辑、不需要多套结局演出，**不需要"玩家抉择"型标志位**
- 标志位系统退化为**进度与解锁记录**（情绪找回状态、图鉴、记忆回看），复杂度大幅下降
- 对白表只写一条主线，QA 只需验一条路径
- 代价：失去「打捞 vs 留驻」的道德两难。**需要用结局演出的密度来补情绪冲击**，而不是用选择

### 6.1 ⚠️ 决策引发的连锁修改（必须同步处理）

**「沉默主角」与 GDD v1.0 现有文本冲突。** GDD 14.1 与 14.5 里主角是有台词的：

| 位置 | 现有文本 | 处理 |
| --- | --- | --- |
| 14.1 开场 | 玩家：「我把它们带回来。」 | ❌ 删除。改为阿渡发问、玩家以动作作答（系紧绑带、望向鱼群游去的方向） |
| 14.5 结局 | 玩家：「先回家。然后，再去看看。」 | ❌ 删除。改为阿渡问「想好往哪里走了吗？」，玩家看向伙伴与浮岛，切路牌，上结束字幕 |

**沉默主角反而给了两个好处**：

1. 阿渡从"功能 NPC"升级为**玩家的声音** —— 他说的每句话都在替玩家表态。这需要在他的角色档案里明确写死
2. 结局最后一句台词落回环境（路牌、海面、门）而不是人嘴里，**收束更克制、更契合「治愈不靠说出来」的基调**

**边界（不能越线）**：沉默 ≠ 无表情。主角必须在每个节拍有**明确的可读动作反应**，否则会显得像个空壳。第 7 节的场景卡新增一个必填字段：**主角动作反应**。

| 愤怒 · 灼流腔室 | 找回被反复覆盖的边界声明 |
| 孤独 · 远灯静海 | 将三处孤立信号接到同一频道 |

### 9.1 首领战的「正视」机制（Q18 定稿）

用户要求：**「对该类情绪需要正视」的领悟，要在结尾的首领决战中体现。**

由此定下一条硬规则：**四个首领都打不死。** 玩家要做的不是消灭它，而是**面对它**。
这同时兑现了叙事支柱第 1 条（被忽视之物不会被消灭，只会被接住）与 GDD 14.6 的边界（不宣称情绪需要被治愈到完全消失）。

| 章 | 首领 | 面对方式（玩法） | 正视的动作 | 玩家获得的领悟 |
| --- | --- | --- | --- | --- |
| 一 · 悲伤 | 缄泪之壳 | **停下来** —— 强攻只会让它加固外壳；玩家停止移动与攻击数秒，壳才自己松开一道缝 | 看见它 | 我可以难过，也可以继续生活 |
| 二 · 恐惧 | 惊影巡游者 | **照住它** —— 它会回避光；用灯持续照射，它无处可躲、被定住 | 直视它 | 害怕能提醒我寻求帮助 |
| 三 · 愤怒 | 怒潮钳冠 | **给它出口** —— 它不断升压，压是压不住的；玩家把压力引向一个方向释放 | 让它说出来 | 我有权说不，也能选择表达方式 |
| 四 · 孤独 | 无回应之眼 | **回应它** —— 它一直在发信号；玩家用灯回闪，回一次它稳一分，不回应它会越来越暗 | 接住它 | 我可以先发出声音，等待回应 |

> 四个动词构成一条完整序列：**看见它 → 直视它 → 让它说 → 接住它**。
> 这也是玩家的成长线：第一章他只会「停下来看」，到第四章才学会「回应」。
> 四条领悟均取自 GDD 第 110—115 行，本框架只补上「用什么动作抵达这句领悟」。

**写法与设计纪律**：

- 四个首领的**胜利条件必须都是「停止对抗」**，一个例外都不能有（一处例外就破坏主题）
- 首领外形必须保留**「被压制」的痕迹**（结壳 / 影 / 积压的压力 / 渐暗的灯）—— 它不是怪物，是**被压住的东西**
- 每章首领战前，该章的三段线索必须**已经拼出那句话**；首领战演的是「知道之后，还要学会面对」
- 战后演出一律 B 级，呈现**「松开」而不是「爆炸」**
- 这四个机制需要程序侧的可判定状态（停止移动计时 / 持续照射计时 / 压力释放方向 / 回应次数），见第 12 节系统对接

## 11. 模块九：演出规格

**目的**：控制演出成本。**没定分级规则的话，演出会无限膨胀。**

**演出分三级**：

| 级别 | 形式 | 时长上限 | 每章配额 | 可否跳过 |
| --- | --- | --- | --- | --- |
| **A 级 · 全屏演出** | 黑边 + 静帧/过场画面 + 文字 | 25 秒 | ≤ 1 | 是 |
| **B 级 · 就地演出** | 不切镜头，场上物体/生物动画 + 对白 | 12 秒 | ≤ 4 | 是 |
| **C 级 · 微反馈** | 粒子、震动、音效、提示条 | 3 秒 | 不限 | 否 |

**统一规格**：

- 全局**唯一的 A 级演出配额给结局**（GDD 14.5）
- 首领胜利演出一律 **B 级**（现有四段描写已经符合）
- 四幅世界起源记忆画面用 A 级，但做成**可回看的静帧**，不做动画
- 所有演出必须可跳过且可重看，重看入口在据点

**⚠️ 分工边界（Q16 已答：分镜由美术产出）**

策划**不写分镜、不规定镜头运动**，只交付以下六项，其余由美术回填：

| 策划交付 | 美术回填 |
| --- | --- |
| 演出编号 / 章节 / 级别 | 分镜草图与镜号 |
| 时长上限（硬约束） | 镜头运动、构图、景别 |
| **情绪意图**（这一秒玩家该感觉到什么） | 特效、动画、色彩处理 |
| 画面内容（用文字描述发生了什么） | 转场方式 |
| 是否有对白（引用对白表 ID） | —— |
| 可否跳过 / 可否重看 | —— |

> 这样切分的理由：策划负责**「为什么要演这一下」**，美术负责**「怎么演好看」**。
> 策划越界写分镜会让美术返工，美术缺了「情绪意图」就会做出好看但不对的演出 —— 两边都必须拿到完整信息才能动工。

## 12. 模块十：系统对接

**目的**：让策划案能直接变成程序能读的数据。

| 项 | 规定 |
| --- | --- |
| 文本存储 | 全部走 ScriptableObject 或 JSON，**禁止硬编码在代码里** |
| 编号规则 | `DLG_C1_S02_03` = 第一章 / 第 2 场景 / 第 3 条 |
| 标志位命名 | `FLAG_CHAPTER1_DONE`、`FLAG_EMOTION_SADNESS_FOUND` 等，统一前缀 |
| 存档字段 | 情绪找回状态 ×4、图鉴解锁、记忆回看解锁、首领击败 |
| 触发器 | 进入区域 / 击败首领 / 持有道具 / 完成前序任务 / 对话交互 |
| 本地化 | 中文首发，文本表预留 `en` 列，不写死字符串拼接 |

**标志位登记表（必填）**：

| 标志位 | 类型 | 置位条件 | 读取位置 |
| --- | --- | --- | --- |
| `FLAG_EMOTION_SADNESS_FOUND` | bool | 击败缄泪之壳 | 结局判定、图鉴、据点 |
| `FLAG_QUEST_C1_01` | int | 线索已拼合数（0—3） | 任务 UI、首领战解锁 |
| … | | | |

**首领战状态机（9.1 的四条机制要落成可判定状态）**：

| 首领 | 需跟踪的量 | 通关条件 | 僵持/失败条件 |
| --- | --- | --- | --- |
| 缄泪之壳 | 连续静止秒数 / 壳厚度 | 静止 ≥ N 秒，壳自然归零 | **攻击会让壳变厚**（越打越难） |
| 惊影巡游者 | 连续被照射秒数 / 可见度 | 照射 ≥ N 秒 | 停止照射后可见度缓慢衰减 |
| 怒潮钳冠 | 腔内压力 / 已释放次数 | 释放 ≥ 3 次且压力回落 | 压力持续升高，不释放会波及全场 |
| 无回应之眼 | 它发信次数 / 玩家回闪次数 / 亮度 | 回应率达到阈值 | 一次不回则亮度下降，降到 0 本场重置 |

> 变量名仅为示意，**最终命名由程序决定**；策划只保证**机制语义不被改动** ——
> 也就是：「攻击无效」「不看不亮」「不给出口就压爆」「不回应就变暗」这四条语义不能简化掉，否则 9.1 的领悟就不成立了。

## 14. 模块十二：验收标准（叙事 QA）

写完不是结束，要能验收。逐条打勾：

- [ ] 所有演出可跳过，且可从据点重看
- [ ] 无任何一段演出阻塞战斗节奏（B 级 ≤ 12 秒硬上限）

- [ ] 术语表 100% 覆盖，全文无同义混用
- [ ] 每个场景都绑定了一个可判定的退出条件
- [ ] 所有文本 ID 唯一且符合命名规则
- [ ] 四章认知阶梯逐级递进，不存在玩家提前猜到关键真相的路径
- [ ] 结局不违背「叙事边界」中列出的不可变量
- [ ] 未通关玩家不会接触到结局文本（无剧透泄漏）
